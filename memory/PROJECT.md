# PROJECT.md - 项目边界

_描述"这个项目是什么 / 不做什么 / 做到什么程度算完"。_
_和 MEMORY.md 不同：MEMORY.md 记录"我们做了什么决定"，这里记录"项目本身是什么"。_

使用方式：
- 每个 `## <分类>` 是一个稳定的项目维度。
- 条目简短、陈述式，写完就**不要常改**——边界变化时**整段改写**，而不是追加。
- 多条事实用 `- ` 列表，单条也可以直接写成段落。
- 内容来自对话中的明确表态（"我们不做 X"、"目标是 Y"），不要靠 agent 猜。

---

## 目标

- 提供本地优先的卡片收藏管理应用，覆盖卡片、卡组、系列、购买、统计、备份和回收站流程。

## 非目标

- 当前工程基线修复不引入新的网络依赖，也不改变既定产品规则。

## 范围

- Flutter 应用，当前质量门禁覆盖格式、静态分析、数据库迁移、全量测试和 Android debug 构建。

## 约束

- 新卡片的名称和城市必填。
- 月度新增统计按获得日期计算。
- 软删除收藏目标保留审计记录，但不计入有效收藏总额。
- 数据库与图片保持本地优先。

## 成功标准

- Drift 1..8 到 v9 的分步迁移、410 项测试、严格静态分析和 Android debug APK 构建全部通过。
