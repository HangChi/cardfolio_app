# 开发日志

## 2026-07-28 · Feature 004 标签、系列与筛选

- Drift schema 升级到 v4，新增标签、系列、卡片/套卡关联、自定义字段定义和值，并验证 v3→v4 无损迁移。
- 收藏页升级为“卡片 / 套卡 / 系列”三视图，加入六字段搜索、250ms 防抖、组合筛选、标签任一/全部和稳定排序。
- 完成标签创建/重命名/合并/删除及影响预览，完成系列列表/表单/详情，以及文本、数字、日期字段管理。
- 卡片详情与整理页支持类型、入手日期、待完善、标签、系列和字段值的一次性事务保存。
- Feature 004 目标测试 43 项、全量回归 189 项通过；10,000 款式查询低于 300ms；自动化未启动模拟器，设备验收步骤已记录。

自动化证据与真机步骤见 [Feature 004 测试矩阵](../features/004-tags-series-and-filters/test-matrix.md)。

## 2026-07-28 · Feature 003 套卡与完成度

- 收藏页新增“卡片 / 套卡”分页，以及套卡创建、编辑、列表和详情流程。
- 套卡成员支持关联已有款式或定义缺失款式，并可维护编号、必需性、顺序、封面和移除关系。
- 完成度按不同必需款式实时聚合；重复数量不抬高分子，未知总数不展示百分比或集齐状态。
- Drift schema 升级到 v3，新增 `card_sets`、`card_set_members` 与 v1/v2 无损迁移测试。
- 图片或成员失效时套卡封面同步失效；删除封面图片会在同一事务中清理引用。
- 未启动模拟器；Android/iOS 重启、200% 字体、读屏和多宽度留作设备验收。

自动化证据与手动步骤见 [Feature 003 测试矩阵](../features/003-card-set-progress/test-matrix.md)。

## 2026-07-28 · Feature 002 多图与封面

- 建卡相册入口升级为多选；草稿支持稳定图片 ID、六种用途和前后移动。
- `CardImage` schema 升级到 v2，增加派生图路径、封面标记和图片软删除；v1 单图迁移后自动成为封面。
- 新增既有藏品追加图片、用途更新、完整重排、独立设封面、删除影响和两种删除策略。
- 单藏品限制 20 张；批量文件或事务失败会补偿本批次导入文件。
- 详情页新增有序图集、用途/封面语义、管理面板和删除空间提示。
- 未启动模拟器；Android/iOS 系统相册、权限、强停重启、真实大图和 200% 字体留作设备验收。

自动化证据见 [Feature 002 测试矩阵](../features/002-multi-image-management/test-matrix.md)。
