# 开发日志

## 2026-07-29 · Feature 007 回收站与永久删除

- 卡片详情新增软删除入口；“我的”新增回收站页面，支持恢复、影响预览和二次确认永久删除。
- Drift schema 升级到 v6，新增 7/30/90 天保留期设置与持久化文件清理队列，并验证 v1–v5 到 v6 迁移及 v5 数据保留。
- 软删除保留图片、标签、系列、自定义字段、购买快照和套卡款式关系；恢复只切换藏品状态，原关联完整回归。
- 永久删除事务先记录原图/派生图清理意图，再清理套卡封面引用、购买目标、图片和藏品实例；失败文件在启动时继续重试。
- 应用启动执行到期永久删除和待清理队列，然后按最新数据库引用清理孤儿图片。
- Feature 007 新增 17 项自动化；全量主机测试 272 项与静态分析通过，未启动模拟器或真机。

自动化证据与手动步骤见 [Feature 007 测试矩阵](../features/007-recycle-bin/test-matrix.md)。

## 2026-07-28 · Feature 006 首页与统计查询

- 新增只读 dashboard 领域、仓储和 Drift 聚合，不增加事实表或不可重建缓存。
- 首页交付实体/款式/套卡/已集齐/本月新增、多币种成本、最近录入、差 1 款和待补资料。
- 统计页交付发行年份、城市、机构、类型、标签和套卡状态六维分布，以及按月/原币种的成本趋势。
- 收藏共享查询新增机构与套卡状态条件；统计桶下钻先写入同一 `CardLibraryQuery` 再进入收藏页。
- 本地自然月同时校验上下界；软删除排除、重复实体、未知套卡、多标签、多币种和退款均有内存 SQLite 自动化。
- Feature 006 目标测试 42 项、全量回归 246 项和静态分析通过；10,000 款式聚合低于 1,200ms 门槛。
- 自动化未启动模拟器或真机；多宽度、200% 字体、底栏分支和返回行为留作设备验收。

自动化证据与手动步骤见 [Feature 006 测试矩阵](../features/006-dashboard-and-statistics/test-matrix.md)。

## 2026-07-28 · Feature 003 套卡与完成度

- 收藏页新增“卡片 / 套卡”分页，以及套卡创建、编辑、列表和详情流程。
- 套卡成员支持关联已有款式或定义缺失款式，并可维护编号、必需性、顺序、封面和移除关系。
- 完成度按不同必需款式实时聚合；重复数量不抬高分子，未知总数不展示百分比或集齐状态。
- Drift schema 升级到 v3，新增 `card_sets`、`card_set_members` 与 v1/v2 无损迁移测试。
- 图片或成员失效时套卡封面同步失效；删除封面图片会在同一事务中清理引用。
- 未启动模拟器；Android/iOS 重启、200% 字体、读屏和多宽度留作设备验收。

自动化证据与手动步骤见 [Feature 003 测试矩阵](../features/003-card-set-progress/test-matrix.md)。
