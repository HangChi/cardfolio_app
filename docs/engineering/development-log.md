# 开发日志

## 2026-07-28 · Feature 002 多图与封面

- 建卡相册入口升级为多选；草稿支持稳定图片 ID、六种用途和前后移动。
- `CardImage` schema 升级到 v2，增加派生图路径、封面标记和图片软删除；v1 单图迁移后自动成为封面。
- 新增既有藏品追加图片、用途更新、完整重排、独立设封面、删除影响和两种删除策略。
- 单藏品限制 20 张；批量文件或事务失败会补偿本批次导入文件。
- 详情页新增有序图集、用途/封面语义、管理面板和删除空间提示。
- 未启动模拟器；Android/iOS 系统相册、权限、强停重启、真实大图和 200% 字体留作设备验收。

自动化证据见 [Feature 002 测试矩阵](../features/002-multi-image-management/test-matrix.md)。
