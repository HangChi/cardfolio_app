# 开发日志

## 2026-07-29 · Feature 010 账号与本地优先同步

- 新增可选账号注册/登录、安全会话存储、同步开关、手动重试、退出保留本地副本和账号删除选择。
- Drift schema 升级到 v7，新增同步设置、云端基线、持久 outbox 和冲突副本，并验证 v1–v6 前向迁移。
- 16 类业务实体通过稳定操作 ID、服务端版本、增量游标和三方合并实现本地优先同步；同字段及删除/修改冲突保留双方副本。
- 原图与派生图在元数据前上传，下载按 SHA-256 校验后原子发布；HTTPS REST v1 隔离具体服务商。
- 提供 Supabase RLS、操作幂等、租户私有对象和账号数据清理参考迁移，以及隐私、威胁、可观测性与回滚基线。
- Feature 010 定向宿主机测试 88 项、全量无设备回归 377 项和静态分析通过；未启动模拟器或真机。

自动化证据与双设备手动步骤见 [Feature 010 测试矩阵](../features/010-account-and-local-first-sync/test-matrix.md)。

## 2026-07-29 · Feature 009 相机与图片处理

- 开放系统相机单张和连续拍摄，支持取消、20 张上限、Android 丢失结果恢复，并保留相册入口。
- 新增 isolate 本地处理管线，覆盖 EXIF 方向、边缘建议、手动四角、透视、旋转、亮度、
  对比度、清晰度和四种展示模板。
- 编辑页支持原图比较、撤销、重置和错误重试；处理结果原子输出为 JPEG，原图字节不覆盖。
- 草稿、仓储和受管文件存储贯通 `derived/` 派生图，失败时补偿本批次文件，孤儿清理同时覆盖派生图。
- 添加 iOS 相机与相册用途声明；全量无设备回归 339 项和静态分析通过，未启动模拟器或真机。

自动化证据与设备手动步骤见 [Feature 009 测试矩阵](../features/009-camera-and-image-processing/test-matrix.md)。

## 2026-07-29 · Feature 008 导出、导入与迁移

- 新增版本化完整 ZIP 备份，包含 17 类逻辑实体、受管图片、清单、大小和 SHA-256，
  不导出绝对路径、令牌或日志。
- 导入先复制到临时目录，并验证格式版本、路径、条目数量、解压大小、压缩比、校验和、
  UUID、字段和关系；损坏或不兼容文件不会修改收藏库。
- 支持空库恢复和仅新增合并；相同记录跳过，同主键不同内容阻断并显示冲突预览。
- 图片先 staging，数据库与文件提交失败执行事务回滚和本批次文件补偿；处理过程支持
  进度、提交前取消和脱敏报告。
- “我的”新增“导入与导出”，桌面使用保存/打开选择器，移动端使用打开选择器和系统
  分享面板，并明确提示私人图片、备注与购买信息风险。
- Feature 008 专项 29 项、完整无设备回归 303 项和静态分析通过；未启动模拟器或真机。

自动化证据与手动步骤见 [Feature 008 测试矩阵](../features/008-import-export-and-migration/test-matrix.md)。

## 2026-07-29 · Feature 007 回收站与永久删除

- 卡片详情新增软删除入口；“我的”新增回收站页面，支持恢复、影响预览和二次确认永久删除。
- Drift schema 升级到 v6，新增 7/30/90 天保留期设置与持久化文件清理队列，并验证 v1–v5 到 v6 迁移及 v5 数据保留。
- 软删除保留图片、标签、系列、自定义字段、购买快照和套卡款式关系；恢复只切换藏品状态，原关联完整回归。
- 永久删除事务先记录原图/派生图清理意图，再清理套卡封面引用、购买目标、图片和藏品实例；失败文件在启动时继续重试。
- 应用启动执行到期永久删除和待清理队列，然后按最新数据库引用清理孤儿图片。
- Feature 007 新增 17 项自动化；全量主机测试 272 项与静态分析通过，未启动模拟器或真机。

自动化证据与手动步骤见 [Feature 007 测试矩阵](../features/007-recycle-bin/test-matrix.md)。

## 2026-07-28 · Feature 006 首页与统计查询

- 新增只读 dashboard 领域、仓储和 Drift 聚合，不增加事实表或不可重建缓存。
- 首页交付实体/款式/套卡/已集齐/本月新增、多币种成本、最近录入、差 1 款和待补资料。
