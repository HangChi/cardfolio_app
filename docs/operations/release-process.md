# 发布流程

## 1. 准备

1. 冻结发布范围和 PRD 追踪矩阵。
2. 确认所有目标 Feature 达到完成定义。
3. 更新版本号、迁移说明、隐私声明和发布说明。
4. 完成发布检查清单与兼容性矩阵。

## 2. 候选版本

- 从 `main` 的已审查提交创建候选构建。
- 使用正式签名配置构建，不在开发机暴露密钥。
- 在干净设备和从上一版本升级的设备上验收。
- 候选版本只允许修复发布阻断问题；修复后重新执行受影响与全量门禁。

## 3. 发布

- 创建不可变版本标签。
- 先发布到内部渠道，再小比例 Beta/Production。
- 观察启动、迁移、保存、崩溃和同步指标。
- 满足观察窗口和停止条件后逐步扩大比例。

## 4. 结束

- 记录商店版本、提交、构建产物校验和和发布日期。
- 归档测试、迁移、设备和监控证据。
- 更新路线图状态并召开短复盘。
