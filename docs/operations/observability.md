# 可观测性

## 1. 原则

可观测性用于判断应用是否健康，不收集用户收藏内容。M0 先定义结构化本地事件；接入远端服务前完成隐私与安全评审。

## 2. 事件

| 事件 | 字段 | 不允许字段 |
|---|---|---|
| `app_bootstrap_failed` | 版本、平台、阶段、错误码 | 数据库路径、异常明文数据 |
| `card_save_failed` | 阶段、错误码、耗时 | 名称、备注、图片 |
| `migration_failed` | from/to 版本、错误码 | 表内容 |
| `import_failed` | 格式版本、阶段、错误码 | 导入包内容 |
| `sync_conflict` | 实体类型、策略、匿名操作 ID | 用户字段值 |

## 3. 指标

- 崩溃自由会话率；
- 启动失败率与启动耗时；
- 卡片保存失败率与耗时；
- 数据库迁移失败率；
- 导入/导出成功率；
- Feature 010 的同步积压、失败率和冲突率。

## 4. 告警

正式阈值在具有真实基线后冻结。发布期间若出现迁移失败、数据完整性错误、崩溃率显著上升或保存失败集中，立即暂停分阶段发布并按回滚计划处理。

## 5. 本地诊断

本地日志采用环形容量限制，可由用户主动导出。导出前展示内容类别并允许取消。日志包括时间、错误码、操作阶段、应用版本和平台，不包含业务内容。
