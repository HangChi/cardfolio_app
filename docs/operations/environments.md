# 环境与配置

## 1. 环境

| 环境 | 用途 | 数据 |
|---|---|---|
| Local | 开发与单元测试 | 合成数据、临时目录 |
| Internal | 团队设备验收 | 专用测试数据 |
| Beta | 小范围发布验证 | 用户自愿创建的数据 |
| Production | 正式发布 | 用户真实数据 |

M0 无远端服务，环境差异主要体现在构建标识、诊断开关和发布渠道。Feature 010 引入服务端后，为每个环境使用独立端点、客户端标识和数据存储，禁止跨环境同步。

## 2. 配置规则

- 非敏感构建配置通过编译期常量注入。
- 密钥和签名材料只存在于平台安全存储或 CI 密钥系统。
- 应用启动时验证必需配置，配置错误进入明确阻断状态。
- 生产构建关闭调试菜单、详细异常和测试后门。

## 3. 数据隔离

不同应用 ID/Bundle ID 的测试渠道使用独立私有目录。导出包显式记录应用格式版本，但不得自动把测试数据导入生产。任何生产数据复制到测试环境前必须去标识化并获得授权。
