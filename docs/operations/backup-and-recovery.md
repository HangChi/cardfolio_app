# 备份与恢复

## 1. M0 边界

M0 的系统备份能力不作为唯一恢复方案。Feature 008 提供可验证的显式导出与导入；Feature 010 提供可选同步，但本地数据仍是可用副本。

## 2. 导出包

导出包包含：

- 格式版本和创建时间；
- 数据库逻辑快照，不直接复制打开中的数据库文件；
- 卡片原图/派生图、套卡独立封面、集卡册封面及其他全部引用托管图片；
- 文件清单、大小和 SHA-256；
- 不含访问令牌、设备绝对路径和诊断日志。

## 3. 恢复流程

1. 用户选择导入包；
2. 复制到 App 临时目录；
3. 验证格式版本、空间、清单和校验和；
4. 在隔离数据库中解析并验证关系；
5. 生成导入预览和冲突策略；
6. 用户确认后在事务中写入；
7. 图片移动到托管目录；
8. 失败时回滚数据库并清理本次临时文件；
9. 成功后保留恢复报告。

## 4. 演练

每个正式版本至少验证：

- 当前版本导出后全量恢复；
- 上一版本导出包升级导入；
- 损坏包、缺图、磁盘不足和重复导入；
- 恢复后数量、关系、金额、软删除、套卡/集卡册封面和图片校验和一致。

## 5. 用户责任提示

导出文件离开 App 私有目录后由用户选择的目标位置保护。界面需建议把备份保存在可信位置，并提醒包含私人图片和购买信息。
