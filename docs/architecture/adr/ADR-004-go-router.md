# ADR-004：go_router 声明式路由

日期：2026-07-26
状态：Accepted

## 背景

Figma 定义五入口主导航及创建、详情、套卡、统计和设置等子流程。路由需要支持稳定路径、深链准备、测试和导航壳。

## 决策

使用 go_router 管理声明式路由。五个主入口使用状态保持的导航壳；创建、详情、冲突和编辑等任务流可在壳外展示。

## 理由

- 路径和参数可测试、可追踪。
- 支持嵌套导航和未来深链。
- 避免在 Widget 中散落 `Navigator` 栈规则。
- 符合 Flutter 官方对大多数应用的推荐方向。

## 后果

- 路径常量集中定义。
- 实体详情使用稳定 ID 参数，不传数据库对象。
- 临时草稿不通过 URL 序列化敏感路径；由状态容器或草稿 ID 获取。
- 导航重定向不得执行数据库写入。

## 未采用

- 仅 Navigator 1.0：小范围可行，但主导航和深链扩展成本较高。
- 自建 RouterDelegate：能力过重且维护成本无必要。
