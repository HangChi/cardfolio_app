# ADR-006：UUID、UTC 时间和实体版本

日期：2026-07-26
状态：Accepted

## 背景

本地无账号创建和未来多设备同步要求实体身份不依赖服务端；时间戳本身不足以表达并发版本。

## 决策

- 核心实体使用客户端生成 UUID。
- 持久化时间统一为 UTC，展示时转换为本地时区。
- 可同步实体使用独立整数 `version`，每次成功业务修改单调增加。
- 测试通过注入 `IdGenerator` 和 `Clock` 获得确定结果。

## 理由

- 离线创建无需等待服务端。
- 合并不同设备数据时 ID 冲突概率可忽略。
- UTC 避免时区切换改变事实时间。
- 独立版本比 `updatedAt` 更适合乐观并发和幂等判断。

## 后果

- UUID 不承担排序语义；排序必须使用明确字段和 ID 稳定兜底。
- 客户端时间不作为跨设备冲突唯一裁决。
- 业务更新必须在同一事务增加版本。
- 导入保留原 ID；合并冲突按导入策略处理，不静默重写。

## 未采用

- 自增整数作为跨设备 ID：合并需要重映射。
- 时间戳作为 ID 或版本：受时钟偏差和并发影响。
