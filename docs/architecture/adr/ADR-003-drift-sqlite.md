# ADR-003：Drift/SQLite 本地持久化

日期：2026-07-26
状态：Accepted

## 背景

卡迹领域包含多对多关系、事务、完成度聚合、成本查询、软删除、迁移和导出。简单键值存储无法可靠表达这些约束。

## 决策

使用 SQLite 作为本地事实来源，使用 Drift 提供类型安全 schema、查询、响应式数据流、事务和迁移工具。

## 理由

- 关系模型适合卡片、套卡、标签、购买和同步队列。
- 事务支持可见原子性。
- 类型安全查询降低动态 Map 映射错误。
- schema 快照和迁移测试符合 NFR-DATA-003。
- Android/iOS 共享数据语义。

## 后果

- 引入 build_runner 和生成文件。
- schema 修改必须增加版本、快照和迁移测试。
- 业务层通过 Repository 访问，不暴露 Drift 行类型。
- 金额、部分日期和枚举需要明确持久化转换。

## 未采用

- shared_preferences：只适合偏好，不适合收藏关系。
- 直接 sqflite：可用，但需要手写大量映射、流通知和迁移验证。
- 文档型数据库：关系聚合和一致性约束成本更高。
