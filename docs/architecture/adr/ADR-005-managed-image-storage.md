# ADR-005：App 私有目录管理图片

日期：2026-07-26
状态：Accepted

## 背景

系统相册选择结果可能是临时 URI，原文件可能被移动或权限失效。图片又是收藏长期价值和导出/同步的核心数据。

## 决策

用户明确选择或拍摄后，将文件复制到 App 私有支持目录；数据库只保存受控相对路径和校验值。原图、派生图、缩略图和暂存区分层管理。

## 理由

- 不依赖系统相册原路径长期有效。
- 私有目录减少广泛存储权限。
- 相对路径支持迁移、恢复和测试。
- 校验值支持导出一致性和去重分析。

## 后果

- App 承担空间管理、孤儿清理和永久删除。
- 文件与数据库使用补偿和启动恢复保证一致性。
- 原图默认保留策略在 Feature 002 开始前基于实测冻结。
- 云同步只上传用户开启同步范围内的受管理文件。

## 未采用

- 仅保存系统 URI：长期可靠性不足。
- 图片 BLOB 存入主数据库：数据库膨胀、导出和处理成本较高。
- 公共目录作为主存储：权限和隐私边界更复杂。
