# 设备兼容性矩阵

## 1. 发布覆盖

| 平台 | 级别 | 覆盖 |
|---|---|---|
| Android 当前最低支持版本 | 必测 | 启动、相册、权限、保存、重启、导入导出 |
| Android 主流版本 | 必测 | 全量核心流程 |
| Android 最新稳定版本 | 必测 | 全量核心流程与权限变化 |
| 小屏 360dp | 必测 | 布局、键盘、字体缩放 |
| 基准 393dp | 必测 | Figma 视觉对照 |
| 大屏/折叠屏 | 抽测 | 响应式布局与旋转 |
| iOS 当前最低支持版本 | 发布 iOS 前必测 | 全量核心流程 |
| iOS 最新稳定版本 | 发布 iOS 前必测 | 全量核心流程与照片权限 |

实际最低系统版本由 Flutter 稳定版和所选插件共同决定，首次添加平台依赖时冻结到发布配置并更新本表。

## 2. 设备维度

- 至少一台低内存 Android 真机、一台主流真机和一个最新系统模拟器。
- 覆盖浅色/暗色系统设置、200% 字体、中文输入法、低存储空间。
- 覆盖照片权限允许、拒绝、受限和再次授权。
- 覆盖后台杀进程、强制停止、系统选择器返回后恢复。

## 3. 记录格式

每次发布记录设备型号、系统版本、屏幕宽度、构建号、测试人、日期、通过项、失败项和证据链接。未覆盖项必须有明确风险接受人。
