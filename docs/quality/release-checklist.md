# 发布检查清单

## 需求与范围

- [ ] 发布范围与 Feature 文档一致。
- [ ] PRD 验收项在追踪矩阵中有结果。
- [ ] 范围外入口明确禁用或不可见。

## 质量

- [ ] 格式、静态分析、单元、数据、Widget 和端到端测试通过。
- [ ] 从上一正式版本升级的迁移测试通过。
- [ ] 兼容性矩阵必测项完成。
- [ ] 性能指标无未解释回归。
- [ ] 无障碍和 Figma 视觉验收完成。

## 数据与安全

- [ ] 权限文案与实际用途一致。
- [ ] 隐私政策和应用商店数据声明已更新。
- [ ] 日志不包含图片内容、绝对路径、令牌或用户字段。
- [ ] 导出、导入、备份、恢复和回滚路径经过验证。
- [ ] 密钥来自发布系统，不在仓库或构建日志中。

## 构建与发布

- [ ] 版本号和构建号唯一递增。
- [ ] release 构建签名正确且可安装。
- [ ] 发布说明、已知限制和支持渠道已准备。
- [ ] 崩溃监控和版本看板可识别新版本。
- [ ] 分阶段发布比例和停止条件已确认。

## 发布后

- [ ] 核心流程冒烟测试通过。
- [ ] 监控窗口内无异常崩溃、迁移或数据错误。
- [ ] 发布证据归档，版本标签已创建。
