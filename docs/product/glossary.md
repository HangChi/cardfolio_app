# 卡迹领域词汇表

状态：基线版
日期：2026-07-26
事实来源：[PRD v1.0](./卡迹App_PRD_v1.0.md)

## 1. 使用规则

- 产品文案可以使用“卡片”作为易懂称呼；代码和规格必须区分卡片款式与藏品实例。
- 同一术语在 PRD、数据库、代码、测试和埋点中保持相同含义。
- 新术语必须先进入本词汇表，再进入 Feature Spec。

## 2. 核心术语

| 中文 | 英文/代码名 | 定义 | 不包含 |
|---|---|---|---|
| 收藏库 | Collection Library | 当前用户在本地管理的全部收藏数据和图片 | 公共资料库、交易市场 |
| 卡片款式 | CardDefinition | 具有相同卡面和发行资料的一种卡 | 用户实际持有数量 |
| 藏品实例 | CardItem | 用户实际持有的实体卡记录 | 发行资料本身 |
| 图片 | CardImage | 与藏品实例关联的原图或派生图 | 云端公开链接 |
| 封面图 | Cover Image | 列表和详情默认展示的图片 | 必须等同正面图的约束 |
| 原图 | Original Image | 用户拍摄或选择后未经增强覆盖的源文件 | 裁切、模板结果 |
| 派生图 | Derived Image | 根据原图生成的裁切、增强或模板文件 | 原图替换 |
| 套卡 | CardSet | 具有明确或预期成员、可计算完成度的集合 | 宽泛主题分类 |
| 套卡成员 | CardSetMember | 套卡与卡片款式之间带编号、顺序和必需性的关系 | 藏品实例 |
| 系列 | Series | 可跨卡片或套卡的宽泛归类，不强制总数和完成度 | 固定成员套卡 |
| 标签 | Tag | 用户定义的轻量、多对多分类 | 结构化业务字段 |
| 自定义字段 | Custom Field | 用户定义名称、类型和适用范围的结构化字段 | 自由备注 |
| 购买记录 | Purchase | 一次实际支付事实，是累计花费的来源 | 卡片发售价 |
| 购买项目 | PurchaseItem | 购买与卡片或套卡的关联及可选分摊 | 独立付款事实 |
| 发售价 | Issue Price | 发行方公布的资料价格 | 用户累计花费 |
| 分摊金额 | Allocated Amount | 购买总额在对象间的分析性分配 | 再次计入累计花费 |
| 软删除 | Soft Delete | 设置删除时间并从默认查询排除 | 释放文件或不可恢复 |
| 永久删除 | Permanent Delete | 不可恢复地删除记录和相关文件 | 普通删除操作 |
| 回收站 | Recycle Bin | 保存软删除对象并支持恢复的区域 | 默认列表和统计 |
| 本地优先 | Local First | 用户写操作先在本地完成，网络不是核心操作前提 | 永不使用云端 |
| 同步记录 | SyncRecord | 描述待上传、已上传、失败或冲突的本地变更 | 业务实体本身 |
| 冲突副本 | Conflict Copy | 无法自动合并时保留的另一版本实体 | 静默覆盖 |
| 部分日期 | PartialDate | 允许只记录年、年月或完整日期的值对象 | 自动猜测缺失月日 |
| 主币种 | Base Currency | 用户用于可选换算展示的偏好币种 | 原始购买币种替换 |

## 3. 计数口径

| 名称 | 定义 |
|---|---|
| 款式数量 | 未删除的不同 `CardDefinition` 数量 |
| 实体数量 | 未删除 `CardItem.quantity` 的总和 |
| 已拥有成员数 | 未删除且实体数量大于 0 的不同必需成员款式数 |
| 套卡完成度 | 已拥有必需成员数 ÷ 必需成员总数 |
| 累计花费 | 按购买记录事实汇总，并依据设置决定是否包含运费和手续费 |
| 本月新增 | 当前自然月创建或确认入藏的实体数量，具体口径由 Feature 006 固化 |

## 4. 状态词汇

| 状态 | 含义 |
|---|---|
| 草稿 | 尚未完成正式保存、不可进入默认统计的数据 |
| 活跃 | 未软删除、参与默认查询的数据 |
| 已删除 | 设置 `deletedAt`、仅在回收站可见的数据 |
| 待同步 | 本地成功但尚未被服务端确认的变更 |
| 冲突 | 存在无法自动选择唯一正确版本的并发修改 |
| 待补全 | 用户明确标记或缺少配置字段的记录 |
