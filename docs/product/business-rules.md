# 卡迹业务规则汇总

状态：基线版
日期：2026-07-26
事实来源：[PRD v1.0](./卡迹App_PRD_v1.0.md)

本文件用于集中解释跨 Feature 规则。规则 ID 与 PRD 保持一致；Feature Spec 只能引用或收紧规则，不得悄悄改变规则。

## 1. 卡片数量

| ID | 规则 | 主要测试 |
|---|---|---|
| BR-CARD-001 | 卡片总量统计未删除实体数量总和；款式总量统计不同款式数量 | 聚合查询、软删除 |
| BR-CARD-002 | 同款持有 3 张时，款式增加 1，实体数量增加 3 | 数量边界 |
| BR-CARD-003 | 需要分别追踪品相或来源时拆分实例，否则使用 quantity | 编辑与拆分 |
| BR-CARD-004 | quantity 为大于等于 1 的整数 | 值对象、数据库 CHECK |

## 2. 套卡完成度

| ID | 规则 | 主要测试 |
|---|---|---|
| BR-SET-001 | 重复持有同一成员不重复增加完成度 | 重复实体 |
| BR-SET-002 | 已拥有成员以未删除、数量大于 0 的不同必需款式计算 | 聚合查询 |
| BR-SET-003 | 完成度为已拥有必需成员数除以必需成员总数 | 0、部分、完整 |
| BR-SET-004 | 总数未知时不显示百分比和集齐状态 | 未知总数 |
| BR-SET-005 | 删除后立即排除，恢复后重新计入 | 删除恢复 |

## 3. 成本与多币种

| ID | 规则 | 主要测试 |
|---|---|---|
| BR-COST-001 | 累计花费仅以购买记录为事实来源 | 查询口径 |
| BR-COST-002 | 整套购买总额与成员分摊不重复累计 | 整套与分摊 |
| BR-COST-003 | 运费和手续费默认计入，可由用户设置改变展示口径 | 设置组合 |
| BR-COST-004 | 退款和调整使用独立记录，不改写原始购买 | 历史可追溯 |
| BR-COST-005 | 无有效汇率时按原币种分组，不产生虚假单一总额 | 缺失汇率 |
| BR-COST-006 | 发售价属于资料，不属于累计花费 | 字段隔离 |

金额使用最小货币单位整数或等价精确十进制表示，禁止用二进制浮点数承担持久化金额计算。

## 4. 图片与删除

| ID | 规则 | 主要测试 |
|---|---|---|
| BR-IMG-001 | 增强与模板只生成派生图，不覆盖原图 | 文件校验值 |
| BR-IMG-002 | 每个藏品有封面图或明确标记无图 | 保存校验 |
| BR-IMG-003 | 软删除只逻辑删除图片；永久删除后才释放文件 | 文件生命周期 |
| BR-DEL-001 | 回收站记录不参与默认列表、搜索、统计和进度 | 所有默认查询 |
| BR-DEL-002 | 恢复原有关联；关联已永久删除时要求重新选择 | 恢复异常 |

## 5. 本地优先同步

| ID | 规则 | 主要测试 |
|---|---|---|
| BR-SYNC-001 | 用户写操作先提交本地数据库，云端不是本地成功前提 | 离线写入 |
| BR-SYNC-002 | 同步操作具有幂等键，重试不创建重复对象 | 重放 |
| BR-SYNC-003 | 同字段冲突保留双方并生成冲突副本 | 多设备并发 |
| BR-SYNC-004 | 删除与修改冲突不静默永久删除修改内容 | 删除冲突 |

## 6. 通用不变量

- 所有核心实体使用本地 UUID。
- 可同步实体包含创建时间、更新时间和版本号。
- 可删除实体包含可空删除时间。
- 数据库迁移具备前向迁移测试和失败恢复说明。
- 文件与数据库跨边界操作具备补偿或恢复机制。
- 导出包声明 `schemaVersion`、生成时间和校验信息。
- 默认查询明确排除软删除对象，不依赖 UI 二次过滤。
- 用户可见统计必须能够追溯到源记录和口径说明。

## 7. 变更控制

修改业务规则时必须：

1. 更新 PRD 与本文件；
2. 列出受影响 Feature、查询和测试；
3. 提供数据迁移或说明无需迁移；
4. 更新验收矩阵；
5. 在 ADR 或变更日志中记录原因。
