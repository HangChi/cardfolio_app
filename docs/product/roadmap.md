# 卡迹产品路线图

状态：核心客户端基线完成，进入 OCR 修复、设备验收与部署阶段
更新日期：2026-08-09

## 1. 已完成里程碑

| 里程碑 | 已落地范围 | 当前结论 |
|---|---|---|
| M0 项目基线 | PRD、架构、ADR、设计、质量、安全和运维文档 | 已建立 |
| M1 本地卡片闭环 | 新建/编辑、数量、多图、图片管理、持久化 | 客户端已实现 |
| M2 收藏组织 | 套卡、集卡册、标签、自定义字段、筛选、回收站 | 客户端已实现 |
| M3 成本与统计 | 卡片人民币成本、首页、六维统计、趋势和消费日历 | 客户端已实现 |
| M4 高效录入 | 相机、系统裁剪、旋转增强、资料库、批量草稿恢复；OCR 桥接已接入 | 图片与批量流程已实现；OCR 当前不可用，待诊断和真机验收 |
| M5 数据安全 | ZIP 备份/恢复、CSV、清理队列、迁移快照 | 客户端已实现 |
| M6 同步客户端 | 账号、安全会话、outbox、游标、附件和冲突 | 客户端及参考 SQL 已实现 |

“已实现”指代码和对应宿主机验证曾经交付，不等于当前 HEAD 已完成所有真机、跨版本和生产
环境验收。

## 2. 当前最高优先级：发布闭环

1. 复现并修复 OCR 不可用问题，补充原生链路回归测试和 Android/iOS 真机识别证据。
2. 在 Android 稳定版模拟器和至少一台真机完成核心冒烟、相机、裁剪、分享和回收站。
3. 在 macOS 环境完成 iOS 构建、Vision OCR、系统裁剪、权限、分享和真机验收。
4. 执行 360/393/430dp、宽屏、200% 字体、减少动画和 TalkBack/VoiceOver 验收。
5. 使用真实收藏执行 ZIP 导出 → 空库恢复 → 合并导入和 CSV Excel 打开验证。
6. 部署 REST 网关和 Supabase 迁移，验证 RLS、附件、删除、冲突、账号清理和双设备同步。
7. 持续维护已建立的 CI 门禁，确保格式、分析、迁移、全量测试和 Android 构建不回退。
8. 完成版本号、签名、隐私文本、监控、备份、回滚和商店材料。

## 3. 发布后候选方向

| 方向 | 价值 | 前置条件 |
|---|---|---|
| OCR/资料库扩充 | 提高自动补全覆盖率和可信度 | 真实识别样本、来源授权、质量评估 |
| 收藏分享图 | 方便展示单卡、套卡和集卡册 | 隐私默认值、图片模板、导出性能 |
| 估价与交易记录 | 管理当前价值和出售历史 | 明确估值来源、免责声明和成本口径 |
| 公共资料库协作 | 降低重复录入 | 审核机制、版权、反滥用和账号体系 |
| 同步后台任务 | 提高多设备实时性 | 生产服务稳定、平台后台限制、耗电评估 |

## 4. 当前明确删除或收敛的范围

- 独立“购买记录”入口已移除；用户在卡片新建/编辑中维护人民币卡片金额和运费。
- 收藏页的入手成本排序和常用筛选 UI 已移除；旧本地状态仍保持可解析。
- 拍照后不再强制立即裁剪；用户在资料页主动编辑图片时才进入系统裁剪。
- 当前不做统一 4096px 高清处理；保持裁剪结果像素尺寸，原图独立保留。
- “系列”在产品界面统一为“集卡册”；数据库表名和路由为兼容已有数据继续保留 series。

## 5. 变更门禁

任何新需求需说明用户价值、数据/隐私影响、迁移策略、设备验收、受影响文档及对发布范围的
取舍。未满足这些信息的需求不进入实现。
