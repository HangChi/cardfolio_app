# 导航与信息架构

## 1. 主导航

主导航固定为：

1. 首页 `/home`
2. 收藏 `/library`
3. 拍摄 `/capture`
4. 统计 `/stats`
5. 我的 `/profile`

Feature 001 默认进入 `/library`。未开放入口显示阶段状态，不创建无行为的按钮。

## 2. 业务路由

| 路由 | 参数 | 进入方式 | 退出规则 |
|---|---|---|---|
| `/cards/new` | 进程内草稿引用 | 相册选择成功 | 保存进入详情；取消返回来源页 |
| `/cards/:id` | `CardItem.id` | 列表点击或保存成功 | 返回收藏 |
| `/sets/:id` | `CardSet.id` | 套卡列表或卡片关联 | 返回来源页 |
| `/search` | 查询参数由状态持有 | 收藏页搜索 | 返回收藏并保留筛选 |
| `/recycle-bin` | 无 | 我的/数据管理 | 返回我的 |

路由参数只传稳定 ID，不传数据库实体、文件对象或大型图片字节。

## 3. 返回行为

- 表单无修改：直接返回。
- 表单有未保存修改：显示“放弃修改”确认。
- 系统选择器取消：停留在来源页，不显示错误。
- 保存中：阻止重复保存；返回操作需等待当前事务结束并显示进度。
- 深链记录不存在：显示内容缺失状态，并可返回收藏。
- 主导航再次点击当前入口：回到该入口根页面。

## 4. 状态恢复

- 收藏筛选和滚动位置在同一会话中恢复。
- 创建草稿不跨进程持久化；图片尚未提交前不得进入托管目录的正式记录。
- App 重启后从数据库恢复已提交内容。
- Feature 010 引入账号后，路由仍只依赖本地 ID，远端 ID 作为映射字段处理。

## 5. 路由守卫

- M0 无登录守卫，核心本地功能无需账号。
- 需要目标实体的页面先加载实体，再渲染内容或缺失状态。
- 数据库启动失败时只显示启动阻断页，不进入业务路由树。
- 永久删除确认使用弹层，不用新路由。
