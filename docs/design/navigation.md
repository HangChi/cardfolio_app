# 导航与信息架构

更新日期：2026-08-01

## 1. 主导航

| 入口 | 路由 | 主要内容 |
|---|---|---|
| 首页 | `/home` | 收藏摘要、总花费、最近录入、即将集齐、待补资料、快捷建卡 |
| 收藏 | `/library` | 卡片/套卡/集卡册三视图、搜索、筛选和排序 |
| 拍摄 | `/capture` | 单卡拍摄、相册导入、批量建卡 |
| 统计 | `/stats` | 固定收藏指标、消费趋势、六维数量分布 |
| 我的 | `/profile` | 账号同步、整理、备份、CSV、回收站和应用设置 |

手机使用底部 NavigationBar；宽屏使用 NavigationRail。五个分支通过
`StatefulShellRoute.indexedStack` 保留各自导航状态。首次安装先进入 `/onboarding`，完成后
默认进入首页。

## 2. 业务路由

| 路由 | 页面 |
|---|---|
| `/cards/new` | 新建卡片 |
| `/cards/batch` | 多卡批量录入与草稿恢复 |
| `/cards/:id` | 卡片详情 |
| `/cards/:id/edit` | 编辑卡片 |
| `/cards/:id/copy` | 复制资料建卡 |
| `/cards/:id/organization` | 卡片整理信息 |
| `/sets/new`、`/sets/:id`、`/sets/:id/edit` | 套卡创建、详情、编辑 |
| `/series/new`、`/series/:id`、`/series/:id/edit` | 集卡册创建、详情、编辑 |
| `/spending-calendar?year=&month=` | 消费日历 |
| `/recycle-bin` | 回收站 |
| `/backup` | ZIP 备份/恢复 |
| `/csv-export` | CSV 导出 |
| `/organization-settings` | 标签与自定义字段管理 |
| `/app-settings` | 主题、权限、存储、诊断和重新查看引导 |
| `/image-editor` | 进程内图片编辑参数页 |

路由只传稳定 ID 或小型进程内参数，不传数据库行和图片字节。集卡册沿用 `/series` 路由
以保持已有深链和本地数据兼容。

## 3. 返回行为

- 业务详情和表单单次返回来源页面；无导航历史的卡片详情回到收藏。
- 主导航根页面在 Android 上第一次返回显示“再按一次返回键退出应用”，2 秒内再次返回退出。
- 系统相册、相机或裁剪取消时停留来源页面，不创建数据也不显示错误。
- 保存期间禁用重复提交；相同草稿使用稳定 ID，数据库唯一约束提供第二层幂等保护。
- 从系统分享回到应用时恢复卡迹路由，不把外部分享内容当作应用根页面。

## 4. 状态恢复

- 主导航分支由 indexed stack 保持会话状态。
- 已提交业务数据由 Drift 恢复；主题、引导和诊断开关由 `app-state.json` 恢复。
- 批量录入的共享资料、逐卡草稿、图片路径和确认状态可跨进程恢复；全部保存成功后清除快照。
- 历史版本保存的常用筛选仍可解析，但当前 UI 不再展示该功能。
- 数据库启动失败只显示可重试阻断页，不进入业务路由树。
