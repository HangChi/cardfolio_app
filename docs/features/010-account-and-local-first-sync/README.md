# Feature 010：账号与本地优先同步

## 目标

用户可在不牺牲本地离线能力的前提下登录并选择同步；离线变更最终上传，重复重试不重复，无法自动合并的修改生成冲突副本。

## 范围

- 账号注册/登录/退出和本地保留选择；
- 同步开关、队列、状态、重试；
- 多设备增量同步、删除墓碑和冲突副本；
- 数据下载、账号与云端数据删除；
- 本地数据始终可离线浏览和编辑。

## 追踪

- FR-ACC-001..002、FR-SYNC-001..003；
- BR-SYNC-001..004；
- NFR-SYNC-001、NFR-DATA-001、SEC-001..004；
- AC-V1-001..003。

## 架构边界

本地数据库仍是客户端读取源。每个实体使用 UUID、UTC 时间、服务端版本和删除语义；
每次操作有稳定幂等 ID。[ADR-009](../../architecture/adr/ADR-009-account-sync-service-and-protocol.md)
选择 Supabase 作为首个服务端实现，并以可替换 REST v1 隔离客户端。

## 风险

静默覆盖、重试重复、删除复活、权限越界、令牌泄露、供应商锁定和费用失控。
