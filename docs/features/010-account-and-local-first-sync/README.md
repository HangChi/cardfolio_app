# Feature 010：账号与本地优先同步

## 目标

用户可在不牺牲本地离线能力的前提下登录并选择同步；离线变更最终上传，重复重试不重复，无法自动合并的修改生成冲突副本。

## 范围

- 账号注册/登录/退出和本地保留选择；
- 同步开关、队列、状态、重试；
- 多设备增量同步、删除墓碑和冲突副本；
- 数据下载、账号与云端数据删除；
- 本地数据始终可离线浏览和编辑。

## 追踪

- FR-ACC-001..002、FR-SYNC-001..003；
- BR-SYNC-001..004；
- NFR-SYNC-001、NFR-DATA-001、SEC-001..004；
- AC-V1-001..003。

## 架构边界

本地数据库仍是客户端读取源。每个实体使用 UUID、UTC 时间、版本和删除墓碑；每次操作有幂等 ID。服务商、协议和认证方案在证据门禁后由 ADR 决定。

## 证据门禁

- 对至少两种后端方案比较离线队列、冲突、附件、成本、数据驻留、删除和供应商锁定；
- 定义服务端权限模型、API/同步协议和威胁模型；
- 通过 20 条离线创建、双设备同字段冲突、退出保留本地三项验收原型；
- 完成隐私政策、数据处理清单和账号删除流程；
- 建立故障注入、重放、时钟偏差和大附件测试基线。

## 风险

静默覆盖、重试重复、删除复活、权限越界、令牌泄露、供应商锁定和费用失控。

## Definition of Ready

证据门禁全部通过，ADR 冻结后端与冲突策略，安全/隐私评审批准，运营监控与事故回滚方案就绪，并建立完整九件套后方可实现。
