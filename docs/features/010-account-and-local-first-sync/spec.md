# Feature 010 规格

## 1. 目标

用户无需账号即可完整使用本地收藏；登录后可选择同步。离线变更恢复网络后最终上传，
重复提交不重复，同字段冲突和删除/修改冲突保留双方。

## 2. 范围

- 邮箱密码注册、登录、刷新、退出与账号删除；
- 同步开关、手动重试、持久化队列、状态、游标和指数退避；
- 16 类用户逻辑实体与原图/派生图附件的增量同步；
- 三方字段合并、冲突副本与保留本地/采用远端/显式合并；
- 退出保留本地，账号删除时选择保留或删除本地副本；
- Supabase RLS/幂等/删除基线及可替换 REST v1 客户端。

## 3. 范围外

社交登录、组织共享库、实时协作、端到端加密、后台常驻任务、远端诊断、计费订阅和
自动选择冲突胜者不在本 Feature。

## 4. 固定约束

- 本地数据库始终是客户端读取源；关闭同步或远端失败不阻塞本地写入。
- 操作 ID 为 UUID，首次入队后重试不得变化；批次最多 100 条。
- pull 游标只在本地事务成功应用完整批次后推进。
- 时间仅用于展示和排序，不作为冲突胜负依据；服务端版本用于乐观并发。
- 令牌只存平台安全存储；生产 API 仅 HTTPS。
- 附件以 SHA-256 去重，私有存储，单文件沿用 64 MiB 上限。
- 删除/修改碰撞和同字段不同值必须生成冲突记录，不静默覆盖。

## 5. 同步实体

同步逻辑备份中的全部用户数据：卡片定义、藏品、图片、套卡、套卡成员、标签及关系、
系列及关系、自定义字段及值、购买及明细、汇率和回收站保留设置。文件清理队列、
sync 表、令牌、绝对路径和日志不上传。

## 6. 完成定义

九件套、ADR、v7 迁移、领域/REST/安全存储/本地 store/仓储/UI、Supabase RLS 基线、
AC-V1 三项原型、全量主机测试和静态分析完成；模拟器与真机步骤留给人工执行。
