# Feature 010 UX 映射

| 状态 | “我的”展示 | 可用操作 |
|---|---|---|
| 未登录 | “本地模式”，说明核心功能无需账号 | 注册、登录 |
| 已登录且关闭 | 账号邮箱、“同步已关闭” | 开启同步、退出、删除账号 |
| 有积压 | 待同步数量与最近错误 | 立即同步、关闭同步 |
| 同步中 | 进度语义和禁用重复提交 | 等待 |
| 已同步 | 最近成功时间 | 立即检查 |
| 有冲突 | 冲突数量置顶 | 比较、保留本地、采用远端 |
| 登录过期 | 本地数据仍可用 | 重新登录 |

退出不使用“删除”文案；账号删除与“删除本地副本”分开确认。密码不回显、不进入错误
提示。200% 字体时卡片纵向增长，操作仍有文本标签和读屏语义。
