# Feature 010 错误场景

| 场景 | 行为 | 用户提示 |
|---|---|---|
| 未配置服务地址 | 本地功能照常，账号按钮不可用 | 当前版本未配置云同步服务 |
| 非 HTTPS 生产地址 | 拒绝请求 | 同步服务配置不安全 |
| 断网/超时/5xx/429 | 保留 outbox，指数退避，允许手动重试 | 暂时无法同步，本地更改已保留 |
| 401 | 安全存储刷新一次；失败则退出远端会话但保留本地 | 登录已过期，请重新登录 |
| 403 | 不重试，不展示服务端细节 | 没有权限访问这份云端数据 |
| 协议版本/载荷错误 | 不推进游标，保留队列 | 云端数据格式暂不兼容 |
| 同字段冲突 | 写冲突副本，不覆盖本地 | 有内容需要你选择保留版本 |
| 删除/修改冲突 | 写冲突副本，不永久删除修改 | 删除与修改发生冲突 |
| 附件校验失败 | 不应用引用该附件的变更 | 图片同步失败，请重试 |
| 账号删除失败 | 保留会话和全部本地数据 | 账号尚未删除，请重试 |
| 本地清理失败 | 云端已删除，记录清理失败并可重试 | 云端已删除，本地清理未完成 |

错误日志只允许错误码、实体类型、匿名操作 ID、次数和耗时；禁止 email、payload、令牌、
图片、绝对路径和服务端响应正文。
