# Feature 010 验收标准

## AC-V1-001 离线创建后同步

离线创建 20 张卡后，扫描得到 20 个稳定操作 ID；首次 push 的响应丢失并重放同一批次，
服务端按操作 ID 返回原 ack，最终远端实体为 20、outbox 为 0。

## AC-V1-002 多设备冲突

两台设备从同一服务端版本修改同一卡片同一字段，后提交设备收到远端变化；本地原值不被
覆盖，冲突表包含本地/远端载荷。删除与另一设备修改同样产生冲突。

## AC-V1-003 退出账号保留本地

完成同步后退出，安全存储令牌被删除、同步关闭；业务表和受管图片保持不变，离线浏览、
编辑和再次入队不依赖账号。

## 补充验收

- 关闭同步不清 outbox、不阻塞本地保存。
- disjoint 字段修改自动合并并以最新服务端版本重新入队。
- 设备时间相差 24 小时不改变冲突结论。
- 游标只在完整 pull 事务成功后推进。
- 账号删除二次确认，保留/删除本地两条路径分别验证。
