# Feature 006 数据模型

Feature 006 不新增持久化表，只定义可重建派生模型。

## HomeDashboard

包含卡片总数、套卡数、集卡册数、本月新增、全时期人民币总花费、最近卡片、差 1 款套卡
和待补资料卡片。最近录入最多 10 项，行动区列表使用各自当前实现上限。

## StatisticsSnapshot

包含固定总卡片/总花费、六个数量维度的 `StatisticBucket` 列表、人民币月度
`CostTrendPoint` 和消费日历入口。卡片维度的值是活跃实体数量；套卡状态的值是套卡数量。

## StatisticBucket

包含稳定键、中文标签、计数和 `CardLibraryQuery` 下钻条件。标签维度使用标签 ID；其余维度使用规范化精确值。

## 删除与时间

所有卡片统计要求款式和藏品均活跃；套卡统计要求套卡和成员活跃；标签桶要求标签活跃。当前月边界由设备本地月初转换成 UTC，持久化时间仍保持 UTC。
