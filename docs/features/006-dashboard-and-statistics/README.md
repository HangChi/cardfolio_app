# Feature 006：首页与统计查询

## 目标

首页展示可解释的收藏摘要，统计页按多维度展示数量和成本，并能下钻到同口径的收藏列表。

## 范围

- 总藏品、款式、套卡、已集齐、累计花费、本月新增；
- 最近录入、即将集齐、待补资料；
- 时间、城市、机构、类型、标签、套卡状态分布；
- 购买金额按时间和币种展示；
- 统计项下钻。

## 追踪

- FR-HOME-001..002、FR-STAT-001..002；
- FR-SCH-001..003；
- NFR-PERF-001..003；
- 与 BR-SET、BR-COST 口径一致。

## 数据影响

统计查询只读，不复制业务事实。可使用可失效的派生缓存，但结果必须能由源数据重建；软删除对象排除在默认口径外。

## 风险

页面与列表口径不一致、缓存失效、多币种误汇总、大库聚合阻塞 UI。

## Definition of Ready

- 每个数字的分子、分母、时间区间和删除口径有说明；
- Figma 首页 `3:17` 与统计 `3:364` 的空/加载/下钻状态齐全；
- 固定大数据集达到性能门槛；
- 下钻筛选与统计查询共享同一条件模型；
- 建立完整九件套后方可实现。
