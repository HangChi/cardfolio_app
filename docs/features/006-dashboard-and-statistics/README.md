# Feature 006：首页、统计与消费日历

状态：客户端已实现，待设备验收
更新日期：2026-08-01

## 首页

- 收藏概览固定展示卡片、套卡、集卡册和本月新增，并支持跳转。
- 本月新增按入手日期的本地自然月统计，点击后进入相同 UTC 边界的卡片筛选。
- 最近录入显示封面并限制 10 条；另有即将集齐和待补资料。
- 累计花费展示全部活跃收藏的全时期人民币净消费，点击进入当前月消费日历。

## 统计

- 顶部固定展示总卡片数和总花费，不随数量分布维度变化。
- 页面顺序为收藏统计、花费趋势、数量分布。
- 数量分布包含发行年份、城市、机构、类型、标签和套卡状态，点击桶下钻收藏列表。
- 城市统一到市级；软删除卡片排除，恢复后重新聚合。

## 消费日历

- 支持前后月份切换、固定六行月历、周一至周日排列和相邻月弱化。
- 展示月净消费、笔数和每日净额；支出与退款使用不同语义颜色。
- 当前月默认选中今天，历史月默认选中最近有记录的日期。
- 当天明细显示卡片名称和金额；单卡成本可跳转卡片详情。
- 趋势月份直接打开对应日历月份。

统计是只读模型，不复制业务事实。关键设备验收包括本地/UTC 月边界、删除恢复、退款正负、
无记录月份、长金额、360/393/430dp、暗色主题、200% 字体和减少动画。
