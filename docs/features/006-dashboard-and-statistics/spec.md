# Feature 006 规格

## 1. 目标

首页提供可解释的收藏摘要和待办入口；统计页提供数量、套卡与原币种成本分布，并可下钻到同口径收藏列表。

## 2. 范围

- 实体、款式、套卡、已集齐、本月新增和累计花费摘要；
- 最近录入、差 1 款集齐和待补资料列表；
- 发行年份、城市、机构、类型、标签和套卡状态分布；
- 按购买月份与原币种的成本趋势；
- 统计桶通过 `CardLibraryQuery` 下钻。

## 3. 范围外

汇率折算、图表导出、保存统计筛选、派生缓存持久化、回收站、云端同步和相机图片性能不在本次范围。

## 4. 统计口径

实体与各卡片维度按活跃藏品 `quantity` 计数；款式按拥有的活跃定义去重。套卡状态沿用 BR-SET。花费沿用 BR-COST，按原币种独立展示。当前月使用设备本地自然月边界。默认排除软删除卡片、款式、套卡、成员和标签。

## 5. 需求追踪

- 核心：FR-HOME-001..002、FR-STAT-001..002、FR-SCH-001..003。
- 规则：BR-SET-001..005、BR-COST-001..006。
- 质量：NFR-PERF-001..002、NFR-UX-001..002、NFR-A11Y-001..002、NFR-TEST-001。

## 6. 完成定义

九件套、聚合查询、共享下钻、首页与统计页完成；数据库、领域、仓储和 Widget 自动化通过；模拟器验收步骤已列出但不伪报执行。
