# Feature 006 规格

状态：当前实现口径（包含首页与消费日历后续增强）

## 1. 目标

首页提供可解释的收藏摘要、全时期人民币净消费和待办入口；统计页提供固定总卡片/总花费、
六维数量分布、人民币消费趋势和同口径下钻。

## 2. 范围

- 卡片、套卡、集卡册、本月新增和累计花费摘要；
- 最近录入、差 1 款集齐和待补资料列表；
- 发行年份、城市、机构、类型、标签和套卡状态分布；
- 按月份的人民币净消费趋势和按日期查看明细的消费日历；
- 统计桶通过 `CardLibraryQuery` 下钻。

## 3. 范围外

汇率折算、图表导出、保存统计筛选、派生缓存持久化、回收站、云端同步和相机图片性能不在本次范围。

## 4. 统计口径

总卡片和各卡片维度按活跃藏品 `quantity` 计数；套卡状态沿用 BR-SET。首页总花费是
全部活跃收藏关联账本的全时期人民币净消费，软删除后排除、恢复后重计。本月新增使用
`acquired_at` 的设备本地自然月边界；消费趋势中卡片快捷成本优先使用入手日期。默认排除
软删除卡片、款式、套卡、成员和标签。

## 5. 需求追踪

- 核心：FR-HOME-001..002、FR-STAT-001..002、FR-SCH-001..003。
- 规则：BR-SET-001..005、BR-COST-001..006。
- 质量：NFR-PERF-001..002、NFR-UX-001..002、NFR-A11Y-001..002、NFR-TEST-001。

## 6. 完成定义

九件套、聚合查询、共享下钻、首页与统计页完成；数据库、领域、仓储和 Widget 自动化通过；模拟器验收步骤已列出但不伪报执行。
