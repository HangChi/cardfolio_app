# Feature 006 错误与边界

| 场景 | 行为 |
|---|---|
| 全库为空 | 首页显示添加第一张卡片；统计维度显示暂无数据 |
| 只有无藏品的缺失款式 | 不计入实体或款式总量 |
| 款式或藏品软删除 | 从首页、统计和下钻默认结果排除 |
| 套卡总数未知 | 不计为集齐，进入“总数未知”桶 |
| 同一款重复持有 | 实体数累加 quantity，套卡完成款式只计一次 |
| 同一卡片多标签 | 各标签桶均计入，桶之和可超过总量 |
| 无购买记录 | 成本摘要和趋势显示空状态 |
| 多币种或无汇率 | 始终按原币种分组，不输出单一合计 |
| 读取失败 | 显示安全文案和重试，不泄露内部异常 |
| 桶下钻无结果 | 收藏页显示筛选无结果并可清除筛选 |
