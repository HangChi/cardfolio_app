# Feature 002 错误与边界

| 场景 | 用户体验 | 数据保证 |
|---|---|---|
| 多选取消 | 安静返回原页 | 无新文件、无记录 |
| 超过剩余容量 | 说明最多 20 张 | 不调用导入 |
| 批量中一张无效 | 指明重新选择 | 本批次文件补偿、数据库不变 |
| 批量事务失败 | 保留当前页面并可重试 | 新行回滚、本批次文件补偿 |
| 排序 ID 缺失/重复 | 提示刷新后重试 | 原顺序不变 |
| 封面目标不存在 | 提示图片已变化 | 旧封面不变 |
| 删除最后一张 | 禁止并说明原因 | 图片和封面不变 |
| 删除封面 | 自动选择剩余第一张 | 始终一个封面 |
| 保留原图删除 | 图集立即移除 | 软删除行继续保护文件 |
| 原图物理删除失败 | 提示稍后自动清理 | 业务图集已更新，孤儿下次重试 |
| schema 迁移失败 | 阻断并允许重试 | 不删库、不覆盖原文件 |

错误文案不得包含绝对路径、SQL、堆栈或原始异常。
