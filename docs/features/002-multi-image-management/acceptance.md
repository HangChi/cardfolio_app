# Feature 002 验收标准

## A1 多图创建

给定空库，当用户一次选择正面、背面和包装图并保存，则只创建一个藏品，三张图片按选择顺序展示，第一张为封面。

## A2 图片管理

在详情中可追加图片、调整六种用途、前移或后移、将任意图片设为封面。封面变更不改变排序，重启后顺序、用途和封面保持不变。

## A3 删除

- 删除前显示用途、是否封面、剩余图片数和原图字节数。
- 默认“从卡片移除并保留原图”；可选择“同时删除原图”。
- 删除封面后，剩余顺序第一张成为封面。
- 最后一张图片不可删除，并显示明确原因。

## A4 失败与容量

- 单藏品第 21 张图片被拒绝且不产生文件或记录。
- 批量任一图片不可读时，本批次无数据库写入，已导入文件被补偿删除。
- 数据库事务失败时，本批次文件全部删除。
- 取消系统选择器无副作用。

## A5 迁移与重启

schema v1 的单图藏品升级后原图片保留、用途为正面、排序为 0、封面为真。多图编辑后强停并重启，详情和列表封面一致。

## A6 UI 与可访问性

360、393、430 宽度及 200% 字体下可完成管理；图片、用途、封面和图标按钮具有语义；保存操作期间禁用重复操作。
