# Feature 002 UX 映射

| 用户步骤 | 页面 | 行为 |
|---|---|---|
| 初次选图 | 新建卡片 | 系统多选，横向预览，第一张标记封面 |
| 编辑草稿图片 | 新建卡片 | 点选用途，拖动的无障碍替代为前移/后移 |
| 查看图集 | 卡片详情 | 大图展示封面，下方按顺序显示缩略图 |
| 追加图片 | 卡片详情 | 按剩余容量打开系统多选 |
| 管理图片 | 卡片详情 | 设置用途、封面、前移、后移、删除 |
| 删除确认 | 底部弹层 | 展示空间影响，默认保留原图，可明确永久删原图 |

## 页面状态

- 选择中、批量导入中、操作失败、达到 20 张上限；
- 图片缺失时保留占位和管理入口；
- 删除最后一张时操作禁用并说明“每张卡片至少保留一张图片”；
- 所有图片语义包含顺序、用途和是否封面。

## 交互约束

封面与顺序是两个概念：设为封面不移动图片。用途使用中文标签“正面、背面、包装、编号、细节、其他”。本 Feature 不打开相机或图片处理页。
