# Feature 002：多图与封面

状态：实现完成，自动化通过，待设备验收

完整规格：[spec.md](spec.md)；测试证据：[test-matrix.md](test-matrix.md)。

## 目标

一个藏品可保存多张图片，标记正面、背面、包装、编号、细节或其他，调整顺序和封面，并保持原图与派生图关系。

## 范围

- 多选或逐张添加；
- 图片类型、排序、封面唯一性；
- 删除图片与原图保留设置；
- 详情图集和封面更新；
- 重启后顺序与引用一致。

不含相机、边缘识别、裁切增强和模板输出，这些属于 Feature 009。

## 追踪

- FR-IMG-001、FR-IMG-006、FR-IMG-007；
- BR-IMG-001..003；
- NFR-DATA-001、NFR-PERF-002；
- AC-P0-004。

## 数据影响

扩展 `CardImage.kind`、排序、封面标识和原图/派生图关联；以事务保证同一藏品只有一个封面。删除前计算引用和空间影响。

## 风险

大图导致内存峰值、多选部分失败、重排并发、删除被引用原图、EXIF 方向不一致。

## 实现结果

- 系统相册一次多选或详情追加，单藏品最多 20 张；
- 六种用途、独立排序与唯一封面；
- 删除影响提示，默认保留原图，也可同时删除；
- schema v1→v2 无损迁移及部分唯一索引；
- 批量失败补偿、软删除引用保护和孤儿清理；
- 领域、数据库、迁移、仓储、控制器和 Widget 自动化覆盖。
