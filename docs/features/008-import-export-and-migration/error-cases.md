# Feature 008 错误场景

| 场景 | 写入 | 用户反馈 | 恢复 |
|---|---|---|---|
| 用户取消文件选择 | 无 | 无错误 | 留在原页 |
| 用户取消复制/验证 | 无 | 已取消 | 清理临时目录 |
| 版本不兼容 | 无 | 备份版本不受支持 | 更新应用或使用兼容版本 |
| 路径穿越/绝对/重复/未知条目 | 无 | 备份结构不安全 | 重新选择可信备份 |
| 条目数、大小、压缩比超限 | 无 | 备份超出安全限制 | 拆分数据或重新导出 |
| 清单缺失、大小或 SHA 不符 | 无 | 备份已损坏 | 使用另一份备份 |
| JSON/UUID/时间/枚举/金额非法 | 无 | 备份数据无效 | 使用另一份备份 |
| 关系断裂或图片缺失 | 无 | 备份不完整 | 重新导出 |
| 空库模式目标非空 | 无 | 当前收藏库不是空库 | 选择仅新增合并 |
| 同键不同内容 | 无 | 存在冲突 | 阻断合并 |
| 临时/目标空间不足 | 无 | 存储空间不足 | 清理空间后重试 |
| 数据库事务失败 | 回滚 | 导入失败，现有数据未改变 | 重试 |
| 图片最终提交失败 | 回滚并补偿 | 导入失败，现有数据未改变 | 重试 |

错误日志只允许错误码、阶段、格式版本和匿名操作 ID；禁止数据内容、图片字节、文件名
之外的绝对路径、卡名、备注和金额明细。
