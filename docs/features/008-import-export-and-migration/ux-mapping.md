# Feature 008 UX 映射

| 状态 | 页面行为 |
|---|---|
| 入口 | “我的”首组提供“导入与导出”入口 |
| 首页 | 两张操作卡：导出完整备份、导入备份 |
| 导出说明 | 明示包含私人图片、备注和购买信息；用户确认后在桌面打开保存选择器、在移动端打开系统分享面板 |
| 选择器取消 | 留在页面，不显示失败 |
| 处理中 | 显示阶段、百分比和取消；提交阶段禁用取消 |
| 导入预览 | 展示来源时间、实体/图片数量、新增、跳过、冲突和模式 |
| 冲突 | 红色语义图标与数量；禁止确认，提示使用空库或解决来源 |
| 成功 | 展示脱敏报告与“返回” |
| 失败 | 展示安全原因和“重新选择/重试”，不丢失现有收藏 |

核心按钮提供可访问名称；360/393/430 宽度与 200% 字体使用可滚动布局，不把状态只用
颜色表达。
