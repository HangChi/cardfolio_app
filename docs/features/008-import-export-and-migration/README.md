## 目标

用户可导出结构化数据与图片的完整备份，在空库或现有库中安全导入，并验证实体、关系、金额和图片一致。

## 范围

- 带格式版本、清单、时间和校验和的 ZIP；
- 导入完整性、空间和兼容性检查；
- 新建库和合并策略；
- 影响预览、进度、取消和恢复报告；
- 跨发布版本的前向迁移。

## 追踪

- FR-DATA-001..002；
- BR-IMG、BR-COST、BR-SYNC 中的数据身份规则；
- NFR-DATA-002..003、SEC-003..004；
- AC-P0-008。

## 数据影响

导出采用逻辑格式，不暴露数据库物理实现。导入在临时目录和隔离数据库完成验证，使用 UUID 与校验和处理重复，最终原子提交。

## 风险

ZIP 路径穿越、压缩炸弹、磁盘不足、版本不兼容、部分提交、重复导入和恶意文件。

## Definition of Ready

- 发布导出格式规范、兼容矩阵和大小限制；
- 威胁模型与路径/压缩防护评审完成；
- 空库、合并、冲突和失败恢复 UX 齐全；
- AC-P0-008 使用全实体夹具逐项校验；
- 建立完整九件套后方可实现。

## 固定门禁

- 备份格式版本：`1`，可导入版本范围：`1..1`。
- 最多 50,000 个 ZIP 条目、2 GiB 总解压大小、64 MiB 单条目大小、
  100:1 最大压缩比。
- 只接受 `manifest.json`、`data.json` 和 `images/` 下的规范相对路径。
- 导入预览完成前不修改数据库或受管图片。
- 模拟器/真机验收只列步骤，本次自动执行不启动设备。
