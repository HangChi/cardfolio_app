# Feature 008 验收

## AC-008-01 完整导出

Given 收藏库包含卡片、图片、套卡、组织关系、购买、汇率、软删除设置和清理队列，
When 用户导出备份，Then ZIP 包含版本、UTC 时间、清单、逻辑快照、全部受管图片与
逐文件 SHA-256，且不包含数据库文件、绝对路径、令牌或日志。

## AC-008-02 空库往返

Given AC-008-01 的备份和空收藏库，When 完整验证并选择空库恢复，Then 所有实体数量、
字段、关系、最小货币单位金额、软删除状态、图片字节和校验和与源库一致。

## AC-008-03 安全失败

Given 路径穿越、重复路径、未知条目、压缩比/大小超限、缺文件、校验不符、非法 JSON、
不支持版本或断裂关系的包，When 预览导入，Then 返回安全错误且数据库和图片目录均不变。

## AC-008-04 合并

Given 已有收藏库和有效备份，When 选择仅新增合并，Then 新 UUID 完整写入、完全相同的
记录跳过；同键不同内容在预览列为冲突并阻断提交。

## AC-008-05 取消与原子性

Given 导出或导入验证仍在复制/校验，When 用户取消，Then 临时文件被清理且收藏库不变。
Given 数据库或文件提交失败，Then 本批次数据库和图片均回滚。

## AC-008-06 兼容迁移

Given 格式版本 1，When 当前导入器打开，Then 经版本迁移入口得到当前逻辑快照；
Given 大于 1 或小于 1 的版本，Then 明确拒绝而不写入。

## AC-008-07 UI

Given 用户进入“我的 → 导入与导出”，Then 可先阅读敏感内容说明后导出，可选择 ZIP
并查看摘要、模式、进度、取消、错误和恢复报告；取消原生选择器不产生错误或写入。
