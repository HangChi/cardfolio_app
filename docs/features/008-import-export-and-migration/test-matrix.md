## 手动设备步骤（未执行）

1. 启动 Android 模拟器或连接真机，运行 `flutter run -d <device-id>`。
   若 Windows 提示插件需要符号链接，先在系统设置中启用“开发者模式”。
2. 创建包含多图/派生图、套卡、标签、系列、自定义字段、购买/退款、汇率和回收站卡片
   的收藏库。
3. 进入“我的 → 导入与导出”，阅读隐私说明；桌面端通过保存选择器、移动端通过系统
   分享面板，把 ZIP 保存到可信目录。
4. 取消一次导出和一次导入选择器，确认无报错、无多余文件、数据不变。
5. 在另一份空库选择 ZIP，核对预览后导入；重启并逐项核对数量、关系、金额、软删除和图片。
6. 再次导入同一包并选择仅新增，核对全部跳过且无重复。
7. 修改源库同 UUID 内容后重新导出，在目标库预览合并，核对冲突阻断。
8. 分别在 360、393、430 逻辑像素宽度和系统字体 200% 下检查无溢出。
