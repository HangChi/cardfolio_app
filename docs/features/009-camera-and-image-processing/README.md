# Feature 009：相机与图片处理

## 目标

验证并产品化相机连续拍摄、边缘识别、手动裁切、透视校正、基础增强和展示模板，同时保留原图。

## 范围

- 相机单张/连续拍摄；
- 自动边缘识别失败后的手动四角；
- 旋转、透视、亮度、对比度、清晰度；
- 原图对比、撤销与派生图；
- 固定比例和背景模板。

## 追踪

- FR-IMG-002..005、FR-IMG-007；
- BR-IMG-001..003；
- NFR-PERF、NFR-DATA、NFR-PLAT；
- Figma 节点 `3:137`、`3:181`。

## Spike 证据门禁

产品化前先完成有截止时间的 Spike，比较插件/原生方案在 Android 与 iOS 的：

- 边缘识别准确率和手动兜底；
- 高分辨率内存、耗时和图像质量；
- EXIF 方向、色彩、HEIC 与权限兼容；
- 原图/派生图存储成本；
- 许可证、维护状态和原生改造成本。

## 风险

设备差异、内存崩溃、处理不可逆、草稿丢失、模型许可和效果承诺过高。

## Definition of Ready

Spike 报告选择方案并记录 ADR；目标设备基准达标；草稿恢复和原图保留规则冻结；设计提供完整编辑状态；建立完整九件套后方可产品化。
