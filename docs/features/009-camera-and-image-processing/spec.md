# Feature 009 规格

## 1. 目标

用户可从拍摄入口拍摄首张卡片图片，并在新建或编辑页面继续逐张添加照片；拍摄完成后直接进入资料页，用户需要时再对图片执行相册式裁剪、
旋转、缩放、亮度、对比度与清晰度处理，并在保存时同时保留不可变原图
和可替换派生图。

## 2. 范围

- `image_picker` 系统相机逐张拍摄，可在同一单卡草稿中重复添加；
- Android 宿主被回收后的丢失拍摄结果恢复；
- Android/iOS 原生相册式裁剪器，支持拖动裁剪框、缩放和旋转；
- 亮度、对比度、清晰度与调整重置；
- 草稿派生图预览以及原图/派生图原子式持久化；
- 既有多图顺序、用途、封面与删除规则保持不变。

## 3. 范围外

视频、自建相机取景器、闪光灯/焦距控制、OCR、云端模型、批量字段识别、无损 RAW、
HEIC 派生图编码、后台跨进程图片处理和自动保存未确认的新建卡片不在本 Feature。

## 4. 固定约束

- 单卡最多 20 张图片；达到上限后禁用继续添加。
- 相机权限仅在点击拍摄时由系统入口申请；拒绝后仍保留相册导入。
- 亮度、对比度范围 `-1..1`，清晰度范围 `0..1`。
- 解码后像素数最多 48MP；不得为了处理放大像素或限制到固定长边，派生 JPEG 质量固定为 95。
- CPU 密集处理在 isolate 执行，取消后不得发布半成品。
- 原图放在 `originals/`，派生图放在 `derived/`；数据库只存受管相对路径。
- 原图校验和只由原图字节计算；增强、模板和撤销不得修改原图。

## 5. 处理顺序

用户选择“裁剪与旋转”时由平台裁剪器输出当前尺寸图片；保存时执行读取与格式识别 →
EXIF 方向归一化 → 像素上限校验 → 亮度/对比度 → 清晰度 → JPEG 编码 → 临时文件原子发布。

## 6. 草稿与保存

首张拍摄返回后直接进入现有新建卡片草稿。用户可在新建页继续选择拍摄或相册；
裁剪只在用户点击图片“编辑”后发生，取消裁剪保留原照片。图片编辑结果只更新草稿的
`derivedSourcePath`；保存时仓储先导入原图和派生图，再提交数据库。任何失败都补偿
本批次已复制文件并保留表单草稿。
