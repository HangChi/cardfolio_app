# Feature 009 规格

## 1. 目标

用户可从拍摄入口拍摄首张卡片图片，并在新建或编辑页面继续逐张添加照片；每张相机图片都可执行自动边缘建议、手动四角、
旋转、透视、亮度、对比度、清晰度与展示模板处理，并在保存时同时保留不可变原图
和可替换派生图。

## 2. 范围

- `image_picker` 系统相机逐张拍摄，可在同一单卡草稿中重复添加；
- Android 宿主被回收后的丢失拍摄结果恢复；
- 归一化四角、低置信度手动兜底、透视矫正；
- 90° 旋转、亮度、对比度、清晰度；
- 原图对比、撤销、重置；
- 原始比例、标准卡片比例、方形浅色和方形深色模板；
- 草稿派生图预览以及原图/派生图原子式持久化；
- 既有多图顺序、用途、封面与删除规则保持不变。

## 3. 范围外

视频、自建相机取景器、闪光灯/焦距控制、OCR、云端模型、批量字段识别、无损 RAW、
HEIC 派生图编码、后台跨进程图片处理和自动保存未确认的新建卡片不在本 Feature。

## 4. 固定约束

- 单卡最多 20 张图片；达到上限后禁用继续添加。
- 相机权限仅在点击拍摄时由系统入口申请；拒绝后仍保留相册导入。
- 四角使用 `0..1` 归一化坐标，必须在边界内且形成非退化凸四边形。
- 亮度、对比度范围 `-1..1`，清晰度范围 `0..1`，旋转为 `0..3` 个顺时针 90°。
- 自动边缘置信度低于 `0.55` 时标记为手动模式，但不阻塞编辑。
- 解码后像素数最多 48MP，处理长边最多 4096px；派生 JPEG 质量固定为 92。
- CPU 密集处理在 isolate 执行，取消后不得发布半成品。
- 原图放在 `originals/`，派生图放在 `derived/`；数据库只存受管相对路径。
- 原图校验和只由原图字节计算；增强、模板和撤销不得修改原图。

## 5. 处理顺序

读取字节并识别格式 → EXIF 方向归一化 → 像素上限校验 → 四角透视矫正 →
顺时针旋转 → 亮度/对比度 → 清晰度 → 模板画布 → JPEG 编码 → 临时文件原子发布。

## 6. 草稿与保存

首张拍摄返回后先进入裁切与增强，确认后进入现有新建卡片草稿。用户可在新建页继续
选择拍摄或相册；每次拍摄后进入裁切，取消相机或裁切只放弃当前图片并保留已有草稿。图片编辑结果只更新草稿的
`derivedSourcePath`；保存时仓储先导入原图和派生图，再提交数据库。任何失败都补偿
本批次已复制文件并保留表单草稿。
