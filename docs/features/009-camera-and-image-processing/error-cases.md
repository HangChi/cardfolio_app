# Feature 009 错误场景

| 场景 | 写入 | 用户反馈 | 恢复 |
|---|---|---|---|
| 用户取消系统相机 | 无 | 无错误 | 留在原页并保留已有草稿 |
| 用户取消主动裁剪 | 无 | 无错误 | 保留编辑前照片和草稿 |
| 相机权限拒绝 | 无 | 需要相机权限，可从相册导入 | 系统设置或相册 |
| 相机不可用 | 无 | 无法打开相机 | 相册 |
| Android 丢失结果为空 | 无 | 无错误 | 保持草稿 |
| 图片不存在/空文件 | 无 | 原图无法读取 | 重拍或重选 |
| HEIC/格式无法解码 | 原图仍可导入 | 当前格式无法处理 | 保留原图或改用 JPEG/PNG |
| 解码后超过 48MP | 无派生图 | 图片分辨率过高 | 使用较低分辨率 |
| 平台裁剪器不可用 | 无 | 当前设备无法打开裁剪器 | 保留原图，可继续保存资料 |
| 处理取消 | 无派生图 | 已取消 | 保留编辑参数 |
| 临时空间不足 | 无派生图 | 无法保存编辑图片 | 清理空间重试 |
| 派生图导入失败 | 补偿原图 | 保存失败，草稿保留 | 重试 |
| 数据库提交失败 | 回滚并删除本批文件 | 保存失败 | 重试 |

错误日志只允许错误码、阶段、像素尺寸和匿名操作 ID，不记录图片字节、绝对路径、
卡名或自由文本。
