# Feature 009 UX 映射

## Figma `3:137` 拍摄入口

- “拍摄单张卡”：打开系统相机，确认后进入新建卡片；
- “连续拍摄”：逐张打开系统相机，取消代表结束，已拍内容保留；
- “创建套卡并拍摄”：保留为后续套卡批量字段流程，本 Feature 不改变套卡数据；
- “从相册导入”：保持现有多选入口；
- 权限或相机错误使用页内 SnackBar，必须说明仍可从相册导入。

## Figma `3:181` 图片裁切与增强

- 顶部：取消、标题、完成；
- 主预览：当前派生预览，提供“按住看原图”的语义按钮；
- 裁切：四角模式和自动建议状态；
- 调整：旋转、亮度、对比度、清晰度；
- 模板：原始、标准卡片、方形浅色、方形深色；
- 底部：撤销、重置、生成展示图；
- 处理中禁用重复生成，失败后参数与历史保留。

## 大字体与无障碍

编辑器使用可滚动布局，按钮不只用图标表达；所有拍摄入口、参数控件、预览和错误
具有语义标签。颜色不是自动识别成功/失败的唯一提示。
