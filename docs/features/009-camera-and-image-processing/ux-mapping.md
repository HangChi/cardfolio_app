# Feature 009 UX 映射

## Figma `3:137` 拍摄入口

- “拍摄单张卡”：打开系统相机，确认后直接进入新建卡片；新建页可继续选择拍摄或相册；
- 不再提供独立“单卡多图连拍”入口，同一单卡的正面、背面和细节通过新建页“添加图片”逐张追加；
- “创建套卡并拍摄”：保留为后续套卡批量字段流程，本 Feature 不改变套卡数据；
- “从相册导入”：保持现有多选入口；
- 权限或相机错误使用页内 SnackBar，必须说明仍可从相册导入。
- 既有卡片和批量建卡的拍摄入口同样直接添加照片；用户在图片操作中主动选择编辑。

## Figma `3:181` 图片裁切与增强

- 顶部：取消、标题、完成；
- 主预览：可缩放查看当前图片，亮度和对比度即时显示；
- 裁切：点击“裁剪与旋转”进入 Android uCrop 或 iOS 相册式裁剪器；
- 调整：亮度、对比度、清晰度；旋转在平台裁剪器内完成；
- 底部：撤销调整、重置调整、使用此图片；
- 不提供独立“生成预览”，保存时才按当前像素尺寸生成派生图。

## 大字体与无障碍

编辑器使用可滚动布局，按钮不只用图标表达；所有拍摄入口、参数控件、预览和错误
具有语义标签。颜色不是自动识别成功/失败的唯一提示。
