## 模拟器/真机手动（不在本次自动执行）

1. Android 主流系统：首次点击单张拍摄，允许权限，确认照片并保存。
2. Android：拒绝权限，确认错误文案和相册入口仍可用；到设置授权后重试。
3. Android：连续拍摄 3 张，第 4 次取消，确认顺序和前三张保留。
4. Android 开发者选项启用“不保留活动”：拍摄返回，确认结果可恢复。
5. iOS 真机：允许/拒绝相机权限各一次；确认 `NSCameraUsageDescription` 文案。
6. iOS 真机：拍摄 HEIC，确认原图可保存；无法处理时出现 JPEG/PNG 降级说明。
7. 两平台：编辑卡面四角、旋转、三项增强和四种模板，按住比较原图，撤销与重置。
8. 12MP 真机图：profile 模式记录处理耗时、峰值内存和 UI 卡顿；主 isolate 不连续阻塞
   超过 100ms。
9. 低存储空间：生成或保存失败后确认没有半成品，原草稿仍可重试。
