# Feature 009 验收

## AC-009-01 单张拍摄

Given 新建草稿为空，When 用户点击“拍摄单张卡”并在系统相机确认照片，
Then 草稿获得稳定图片 ID、原图路径和正面用途并进入新建卡片页；取消不产生错误。

## AC-009-02 连续拍摄

Given 草稿少于 20 张图片，When 用户选择连续拍摄并连续确认多张后取消系统相机，
Then 已确认图片按拍摄顺序保留，第一张为封面候选，取消只结束本轮。

## AC-009-03 权限与恢复

Given 相机权限被拒绝或系统相机不可用，When 尝试拍摄，Then 页面展示安全可恢复错误，
相册入口仍可用。Given Android 返回丢失拍摄结果，When 控制器恢复，
Then 结果只消费一次并进入当前草稿。

## AC-009-04 边缘与手动四角

Given 可解码卡面图，When 打开编辑器，Then 显示自动边缘建议；置信度低于 `0.55`
或识别失败时使用安全内缩四角，并允许用户继续处理。非法、越界或退化四角被拒绝。

## AC-009-05 增强、模板与撤销

Given 编辑草稿，When 修改旋转、四角、亮度、对比度、清晰度或模板，
Then 可预览当前配置、查看原图、逐步撤销并重置；模板只影响派生结果。

## AC-009-06 原图与派生图

Given 已处理图片，When 保存卡片，Then `originals/` 字节及 SHA-256 与来源一致，
`derived/` 保存 JPEG，数据库关联两者且界面优先展示派生图。写库失败时两类新文件
都被补偿删除。

## AC-009-07 性能与取消

Given 12MP JPEG，When 执行处理，Then CPU 密集工作不在 UI isolate 连续阻塞超过
100ms，页面展示处理中状态；用户在提交前取消时不发布临时派生文件。

## AC-009-08 兼容与无障碍

Given Android/iOS 支持版本，Then 相机权限只在触发时出现，按钮和图片具有可访问名称，
大字体仍可滚动完成操作；HEIC 无法解码时保留原图并提示改用 JPEG/PNG 处理。
