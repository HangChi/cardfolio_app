# Feature 003 UX 映射

| 用户步骤 | 页面 | 行为 |
|---|---|---|
| 切换收藏类型 | 收藏 | “卡片 / 套卡”分段切换，保留同一主导航 |
| 创建套卡 | 新建套卡 | 名称、总数模式、预计数量、发行信息、备注 |
| 查看进度 | 套卡详情 | 成员清单轨道、已拥有/缺失/重复摘要 |
| 添加已有成员 | 套卡详情 | 从未加入的已有卡片款式中选择 |
| 定义缺失成员 | 套卡详情 | 输入成员名称和编号，默认必需 |
| 管理成员 | 套卡详情 | 编辑编号/必需性、前移、后移、设封面、移除 |
| 编辑资料 | 套卡详情 | 进入复用表单，保存后返回详情 |

## 视觉方向

沿用 `AppColors` 与 `AppTokens`。套卡详情的标志性结构是纵向“成员清单轨道”：左侧状态节点表达已拥有/缺失/重复，右侧卡面展示名称、编号、必需性和数量。已知进度使用深绿条和明确 `3 / 4` 文本；未知总数以文字卡代替百分比。

## 状态

列表和详情覆盖加载、空、成功、失败、记录缺失；成员覆盖必需/可选、已拥有/缺失/重复；保存中禁用重复提交。200% 字体下卡片允许增高，不固定页面高度。
