# Feature 003 验收标准

## A1 套卡资料

用户可创建名称非空的套卡，选择总数已知或未知，并填写发行信息和备注。已知总数必须大于 0；未知总数不保存预计数量。编辑后列表和详情实时更新。

## A2 成员定义

用户可关联已有卡片款式，也可创建尚未拥有的预期成员。每个成员可填写编号、设为必需或可选、前移、后移和移除；同一款式不能重复加入同一套卡。

## A3 完成度

给定 4 个必需成员，其中 3 个存在活跃藏品且一个成员数量为 2，则展示已拥有 3、缺失 1、重复成员 1、进度 3/4（75%），不得展示 4/4。

## A4 未知总数

总数未知时显示“已拥有 N 款”，不显示百分比、进度条数值或“已集齐”。必需/可选和重复状态仍正常展示。

## A5 删除与恢复

已拥有成员的全部藏品被软删除后，该成员立即变为缺失并退出分子；恢复任一藏品后重新计入。数据库不保存需要手工失效的进度缓存。

## A6 封面

用户可从已拥有成员的活跃图片选择套卡封面。设置封面不改变成员顺序；移除对应成员时清除封面，列表与详情一致。

## A7 UI 与可访问性

360、393、430 宽度及 200% 字体下可创建和管理套卡；进度、缺失、重复和必需状态同时使用文字或图标，不只使用颜色；按钮具有可访问名称。
