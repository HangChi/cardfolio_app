# Feature 003 错误与边界

| 场景 | 用户体验 | 数据保证 |
|---|---|---|
| 套卡名为空 | 聚焦名称并提示 | 不写入 |
| 已知总数小于 1 | 提示输入有效总数 | 不写入 |
| 预计数小于当前成员数 | 说明先移除成员或增大总数 | 资料不变 |
| 同款重复加入 | 说明已在套卡中 | 不新增关系 |
| 缺失成员名称为空 | 提示名称必填 | 款式和成员都不写入 |
| 排序 ID 缺失或重复 | 提示刷新后重试 | 原顺序不变 |
| 封面不属于活跃成员 | 提示重新选择 | 旧封面不变 |
| 独立封面路径为空或不可用 | 保留当前可用封面并提示重试 | 不写入无效引用 |
| 移除成员来源封面成员 | 清除成员封面；独立封面不受影响 | 成员和成员封面同事务更新 |
| 套卡被删除或不存在 | 显示内容缺失并可返回收藏 | 不猜测目标 |
| schema 迁移失败 | 启动阻断并允许重试 | 不清库、不覆盖旧数据 |

未知总数不是错误；界面隐藏百分比和完成状态。零成员套卡显示引导，不显示“已集齐”。
