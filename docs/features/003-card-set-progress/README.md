# Feature 003：套卡与完成度

## 目标

用户可创建套卡、定义必需成员，把卡片款式加入套卡，并查看已拥有、缺失、重复和完成进度。

## 范围

- 套卡资料、封面和预计成员数；
- 成员编号、排序和是否必需；
- 藏品数量到成员拥有状态的计算；
- 总数未知时不显示百分比；
- 套卡详情对应 Figma `3:285`。

## 追踪

- FR-SET-001..003；
- BR-SET-001..005；
- NFR-DATA-001、NFR-PERF-003；
- AC-P0-005。

## 数据影响

新增 `CardSet`、`SetMember` 及款式关联。完成度按不同必需成员计算，重复藏品不增加分子；软删除对象不计入，恢复后重新计算。

## 风险

款式与藏品混淆、未知总数、成员删除、重复关系和统计缓存失效。

## Definition of Ready

- 业务规则对“必需、可选、重复、未知总数”给出示例；
- 数据关系与唯一约束评审完成；
- Figma 套卡空/满/缺失/重复状态齐全；
- AC-P0-005 有确定夹具和查询断言；
- 建立完整九件套后方可实现。
