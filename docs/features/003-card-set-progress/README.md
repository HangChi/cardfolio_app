# Feature 003：套卡与完成度

状态：实现完成，包含 schema v9 独立封面增强，待设备验收
依赖：Feature 001、Feature 002

## 目标

用户可创建套卡、定义必需成员，把卡片款式加入套卡，并查看已拥有、缺失、重复和完成进度。

## 范围

- 套卡资料、独立相机/相册封面、成员卡面封面和预计成员数；
- 成员编号、排序和是否必需；
- 藏品数量到成员拥有状态的计算；
- 总数未知时不显示百分比；
- 套卡详情对应 Figma `3:285`。

## 追踪

- FR-SET-001..003；
- BR-SET-001..005；
- NFR-DATA-001、NFR-PERF-003；
- AC-P0-005。

## 数据影响

新增 `CardSet`、`SetMember` 及款式关联。完成度按不同必需成员计算，重复藏品不增加分子；软删除对象不计入，恢复后重新计算。

## 风险

款式与藏品混淆、未知总数、成员删除、重复关系和统计缓存失效。

业务规则、数据唯一约束、AC-P0-005 夹具和未知总数行为已经冻结。Figma 精确变量仍受既有提取限制约束，实现使用当前 Cardfolio 主题令牌并覆盖空、满、缺失和重复状态。

## 实现结果

- 收藏页新增“套卡”分页，支持创建、编辑和实时进度列表；
- 套卡详情支持关联已有款式、定义缺失成员、编号、必需性、排序、移除和设封面；
- schema v3 新增 `card_sets`、`card_set_members`，v1/v2 均可无损升级；
- schema v9 为 `card_sets` 增加可空 `cover_relative_path`，独立封面优先于成员图片封面；
- 完成度由活跃藏品实时聚合，不保存易失效的缓存；
- 删除成员来源封面图片或移除对应成员时，会在事务中清理成员封面引用；独立封面不受影响。

自动化证据与设备验收步骤见[测试矩阵](test-matrix.md)。
