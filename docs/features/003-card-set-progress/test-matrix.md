## Android / iOS 手动验收步骤

1. 在真实 Android 与 iPhone 各安装一次当前构建，打开“收藏”页并切换到“套卡”，确认空状态和“新建套卡”可读、可点击。
2. 新建“测试四季套卡”，开启“成员总数已知”，填写预计成员数 `4`；保存后确认进入详情，返回列表后仍可看到该套卡。
3. 预先准备春、夏、秋三种已有款式，其中“夏”的数量设为 `2`。在套卡详情关联这三种款式，再通过“定义缺失成员”添加“冬”。
4. 将四个成员都设为必需，填写 `01`–`04` 编号，并执行前移、后移；退出详情再进入，确认顺序和编号保持。
5. 确认详情与列表都显示 `3 / 4`、缺失 `1`、重复 `1` 和 `75%`，不得因“夏”有两张而显示 `4 / 4`。
6. 从已有成员选择套卡封面，返回列表确认封面一致；为该卡保留至少两张图片后删除被选中的封面图，确认套卡回退为空封面且图片删除成功。
7. 移除一个成员，确认只移除套卡关系、不删除收藏中的卡片；若该成员是套卡封面来源，确认封面同步清空。
8. 再新建一套卡并关闭“成员总数已知”，添加成员后确认只显示“已拥有 N 款 / 总数未知”，不显示百分比或“已集齐”。
9. 强制结束 App 后重新打开，重复检查套卡资料、成员顺序、封面和完成度，确认 schema v3 数据保持。
10. 分别在 Android 与 iOS 将系统字体调至约 200%，并启用 TalkBack / VoiceOver；在 360、393、430 等效宽度设备上走一遍列表、表单和详情，确认无溢出，进度、缺失、重复、必需状态可被读出且不只依赖颜色。

软删除藏品后的进度变化已由数据库自动化测试覆盖；完整回收站界面的设备验收将在 Feature 007 实现后执行。
