# Feature 004：标签、系列与筛选

## 目标

用户可用标签、系列、自定义字段和组合筛选组织收藏，并在大数据量下快速搜索和稳定排序。

## 范围

- 标签创建、重命名、合并、删除和多选关联；
- 系列创建及卡片/套卡多对多关联；
- 文本、数字、日期自定义字段；
- 搜索、筛选、排序；保存筛选为 P1 增量。

## 追踪

- FR-SER-001、FR-TAG-001..002、FR-CF-001；
- FR-SCH-001..004；
- 相关标签与搜索业务规则；
- NFR-PERF-002、NFR-CAP-001、NFR-UX-001。

## 数据影响

新增标签、系列、自定义字段定义/值和多对多关联表。搜索模型需支持中文文本、稳定排序、筛选条件 AND 及标签组 AND/OR。

## 风险

标签合并丢关联、自定义字段类型迁移、空值排序、中文搜索体验和 10,000 款式性能。

## Definition of Ready

- 冻结搜索匹配、排序空值和标签组语义；
- 提供筛选面板与无结果设计；
- 查询计划与索引基准达到 PRD 性能目标；
- 标签合并和字段删除有影响预览与回滚测试；
- 建立完整九件套后方可实现。
