# Feature 004：标签、集卡册与筛选

状态：客户端已实现，当前行为已包含后续增强，待设备验收
更新日期：2026-08-01

## 当前能力

- 标签创建、重命名、合并、删除、影响预览和卡片多选关联。
- 集卡册列表、新建、编辑、详情、删除、相机/相册/成员封面，以及卡片/套卡成员跳转。
- 数据库沿用 `series_records`、`series_cards`、`series_sets`，仅产品语义改为“集卡册”。
- 文本、数字、日期自定义字段；品相、发行数量、发售价等保留字段防重复创建。
- 名称、编号、城市、发行方、备注、标签的包含搜索和 250ms 防抖。
- 类型、市级城市、年份、标签任一/全部、套卡状态、重复卡、待完善和入手日期区间组合筛选。
- 创建时间、发行时间、入手时间和名称排序，空日期置后、ID 稳定兜底。
- 收藏页“卡片 / 套卡 / 集卡册”三视图。

## 当前收敛

- 常用筛选 UI 已移除；旧 `app-state.json` 中的筛选仍可解析，避免升级失败。
- 入手成本排序已移除。
- 集卡册详情只展示仍有未删除实体的卡片；软删除关系保留，恢复后自动重新显示。
- 城市筛选和统计统一到市级，不因县/区产生多个桶。

历史规格与测试设计仍见本目录的九件套；当前行为以本页、代码和
[开发日志](../../engineering/development-log.md) 为准。

设备验收重点：复杂组合筛选、重复卡口径、软删除/恢复后的集卡册与计数、封面拍摄、
窄屏/大字体和 10,000 款式查询。
