# Feature 004：标签、系列与筛选

状态：实现完成，自动化验证通过，待 Android / iOS 真机验收
日期：2026-07-28

## 目标

用户可以用标签、系列、自定义字段和组合筛选组织收藏，并在大数据量下快速搜索和稳定排序。

## 已交付

- 标签创建、重命名、合并、删除、影响预览和卡片多选关联；
- 系列列表、新建、编辑、详情、删除，以及卡片/套卡多对多关联；
- 文本、数字、日期三类自定义字段和原子化保存；
- 名称、编号、城市、发行方、备注、标签的包含搜索；
- 类型、城市、年份、标签任一/全部、套卡状态、重复卡、待完善的组合筛选；
- 创建、发行、入手和名称排序，空日期置后、ID 稳定兜底；
- 收藏页“卡片 / 套卡 / 系列”三视图与 250ms 搜索防抖；
- Drift schema v4、v3→v4 无损迁移、索引和事务边界；
- 10,000 款式组合查询低于 300ms 的主机基准。

保存筛选继续作为 P1 增量；按购买成本排序延后到 Feature 005。
