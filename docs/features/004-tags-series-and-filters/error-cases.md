# Feature 004 错误与边界

| 场景 | 用户体验 | 数据保证 |
|---|---|---|
| 标签/系列/字段名称为空 | 聚焦名称并提示 | 不写入 |
| 规范化名称重复 | 提示使用现有项或改名 | 不写入 |
| 合并同一标签或目标不存在 | 提示刷新后重试 | 来源和关系不变 |
| 标签合并中任一步失败 | 提示合并失败 | 整个事务回滚 |
| 删除标签 | 展示关联卡片数量 | 卡片不删除 |
| 字段值类型不匹配 | 标记对应字段 | 旧值不变 |
| 有值字段尝试改类型 | 说明先清空值 | 定义和值不变 |
| 删除字段 | 展示受影响值数量 | 值保留，默认查询隐藏 |
| 系列成员包含未知 ID | 提示刷新后重试 | 旧成员集合不变 |
| 空搜索词 | 按无搜索处理 | 不执行无意义 LIKE |
| 标签 AND 选择空集合 | 按无标签筛选处理 | 不产生空结果陷阱 |
| 日期排序遇到空值 | 空值固定置后 | 稳定 ID 兜底 |
| 搜索无结果 | 说明条件并提供清除 | 筛选状态仅会话持有 |
| schema 迁移失败 | 启动阻断并允许重试 | 不清库、不覆盖旧数据 |
