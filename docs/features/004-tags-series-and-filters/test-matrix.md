## Android / iOS 手动验收步骤

1. 在 Android 和 iOS 真机分别安装 Debug 构建，准备至少 6 张卡：含中文/英文名称、城市、编号、发行方、备注、不同发行日期和两张同款卡。
2. 进入“我的 → 整理管理”，创建 3 个标签和文本、数字、日期各一个自定义字段；验证空名称和重名会提示且不产生重复数据。
3. 打开一张卡片详情，进入“整理信息”，同时设置卡片类型、入手日期、待完善、多个标签、系列和三类字段；保存、返回、重启 App 后确认全部保留。
4. 在整理管理中重命名、合并和删除标签；确认影响数量正确，关联迁移完整，卡片本身不被删除。
5. 在收藏页“系列”标签中新建系列，同时选择卡片和套卡；打开详情确认两类成员分区显示且没有完成度。
6. 在卡片页输入中文、英文大小写、编号、城市、发行方、备注和标签片段；确认约 250ms 后更新结果且清空搜索恢复列表。
7. 组合选择类型、城市、年份、多个标签的“任一/全部”、已/未加入套卡、重复卡和待完善；确认跨维度为 AND，清除筛选恢复列表。
8. 依次选择最近添加、发行日期、入手日期、名称升降序；确认空日期始终置后，重复进入页面时同值项目顺序稳定。
9. 将系统字体调到约 200%，分别在窄屏 Android 与 iPhone 小尺寸设备检查筛选面板、系列表单和卡片整理页：无文字遮挡、按钮可达、列表可滚动。
10. 开启 TalkBack / VoiceOver，确认搜索框、筛选、排序、待完善状态和编辑按钮可被读出并能完成操作。

完成后请在本文件把设备列的 `⏳` 改为 `✅`，并记录设备型号、系统版本和异常截图。
