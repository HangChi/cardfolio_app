# Feature 004 验收标准

## A1 标签生命周期

用户可创建、重命名、合并和删除标签。重名按去空白、大小写不敏感规则阻止；合并后来源标签的全部卡片关系出现在目标标签，删除或合并都不删除卡片。

## A2 卡片标签

一张卡可关联多个标签。卡片整理页优先显示最近使用标签并允许就地新建；保存后详情和搜索筛选实时更新。

## A3 系列

用户可创建、编辑和删除系列，把任意卡片款式及套卡加入多个系列。系列详情分别展示卡片和套卡，不计算完成度。

## A4 自定义字段

用户可创建文本、数字或日期字段，并为卡片填写类型匹配的值。删除字段前展示受影响值数量；存在值时不能直接改变字段类型。

## A5 搜索

名称、编号、城市、机构、备注或标签包含搜索词时命中。空白搜索词等同于无搜索；中文原文可命中；软删除数据不命中。

## A6 组合筛选

类型、城市、年份、套卡关系、重复、待补全与标签组之间使用 AND。标签“满足任一”命中任意选中标签，“满足全部”要求具备全部选中标签。

## A7 稳定排序

创建时间、发行时间、入手时间和名称均可升降序。发行/入手时间空值固定在末尾；主键作为稳定兜底，相同业务排序值不会跳动。

## A8 性能

包含 10,000 款式的本地主机 SQLite 固定夹具中，典型搜索+标签+排序查询小于 300ms；搜索输入防抖为 250ms并展示加载状态。

## A9 UI 与可访问性

360、393、430 宽度及 200% 字体下可访问收藏三视图、筛选面板、系列与整理管理；筛选模式、影响和危险操作使用文字表达，图标按钮具备可访问名称。
