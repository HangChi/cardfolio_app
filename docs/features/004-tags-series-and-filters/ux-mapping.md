# Feature 004 UX 映射

| 用户步骤 | 页面 | 行为 |
|---|---|---|
| 切换收藏类型 | 收藏 | “卡片 / 套卡 / 系列”分页 |
| 搜索收藏 | 收藏·卡片 | 250ms 防抖，输入后保留明确加载状态 |
| 组合筛选 | 筛选底部面板 | 类型、城市、年份、标签模式、套卡、重复、待补全 |
| 调整排序 | 收藏·卡片 | 字段与升降序，空日期固定置后 |
| 查看系列 | 系列列表/详情 | 分区查看卡片和套卡成员 |
| 编辑系列 | 系列表单 | 名称、说明、卡片和套卡多选 |
| 整理卡片 | 卡片详情/整理页 | 类型、待补全、入手时间、标签、系列和字段值 |
| 管理标签 | 我的·整理管理 | 新建、重命名、合并、删除和影响确认 |
| 管理字段 | 我的·整理管理 | 新建、重命名、类型标识、删除影响确认 |

## 视觉方向

沿用 `AppColors` 与 `AppTokens`。收藏搜索区使用紧凑的“筛选书签条”作为本功能识别点：每个有效条件都显示可读文字，标签组明确写出“任一/全部”。系列详情用卡片与套卡双区清单，不借用套卡进度视觉，避免暗示完成度。

## 状态

列表、详情和管理页覆盖加载、空、成功、失败和记录缺失。搜索无结果说明当前条件并提供“清除筛选”；保存中禁用重复提交；合并/删除弹窗展示明确影响数量。200% 字体下筛选摘要允许换行，页面不固定高度。
