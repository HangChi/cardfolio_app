# Feature 004：标签、系列与筛选

状态：实施中
依赖：Feature 001、Feature 003
上游：[PRD](../../product/卡迹App_PRD_v1.0.md)
详细设计：[Feature 004 设计](../../superpowers/specs/2026-07-28-feature-004-tags-series-and-filters-design.md)

## 1. 用户结果

用户可创建和维护标签、把卡片与套卡加入多个系列、为卡片款式填写文本/数字/日期自定义字段，并通过搜索、组合筛选和稳定排序快速找到收藏。

## 2. 范围内

- 标签创建、重命名、合并、删除和卡片多选关联；
- 系列创建、编辑、删除及卡片/套卡多对多关联；
- 卡片款式文本、数字、日期自定义字段定义和值；
- 卡片类型、待补全和入手时间整理元数据；
- 名称、编号、城市、机构、备注和标签搜索；
- 类型、城市、发行年份、标签、套卡关系、重复、待补全筛选；
- 创建时间、发行时间、入手时间和名称稳定排序；
- schema v3 到 v4 无损迁移与 10,000 款式查询基准。

## 3. 范围外

保存筛选属于 FR-SCH-004 P1；入手成本排序依赖 Feature 005；标签统计下钻属于 Feature 006；标签/系列恢复与永久删除属于 Feature 007；导入导出属于 Feature 008。

## 4. 规则

- 活跃标签规范化名称唯一；规范化为去首尾空白并转小写，中文保持原文。
- 标签关联卡片款式；删除或合并标签不删除卡片。
- 合并标签在单事务迁移全部关系，已存在的目标关系不得造成重复。
- 卡片和套卡都可加入多个系列；系列不计算完成度。
- 自定义字段定义和值分离；值类型必须匹配定义；有值时不可改变类型。
- 文本搜索使用大小写不敏感包含匹配；中文不分词。
- 不同筛选维度 AND；标签组可切换 OR/AND。
- 发行/入手时间空值始终排在非空值之后；所有排序用藏品 ID 稳定兜底。
- 默认查询排除软删除卡片、标签、系列、字段和关系。
