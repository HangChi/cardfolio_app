# Feature 005：成本账本

状态：底层账本保留，当前用户流程已收敛为卡片内人民币成本
更新日期：2026-08-01

## 当前用户流程

- 新建、编辑和批量录入卡片时直接填写“卡片金额”和“运费”。
- 金额固定人民币，最多两位小数，持久化为 CNY 分；两项都为空或 0 时不保存成本。
- 每张卡使用稳定内部购买 ID 更新同一条记录，修改成本不会重复累计。
- 卡片详情显示卡片金额、运费和合计；独立购买列表、创建购买、退款入口已从路由和 UI 移除。
- 收藏页的入手成本排序已移除。

## 保留的兼容能力

`purchases`、`purchase_items` 和 `exchange_rates` schema 继续存在，用于：

- 兼容此前创建的普通购买、多目标分摊、退款和多币种数据；
- 首页、统计和消费日历的事实查询；
- ZIP 备份、迁移和账号同步协议兼容；
- 在不破坏旧数据的前提下逐步收敛产品流程。

## 当前统计口径

- 首页累计花费是全部活跃收藏的全时期人民币净消费总额。
- 卡片快捷成本按入手日期进入趋势/日历，无入手日期时回退到账本日期。
- 历史普通购买和退款继续按账本日期；退款为负向调整。
- 回收站卡片不计入；恢复后重新计入。
- 发售价属于资料，不属于实际消费。

历史九件套记录了原始完整购买模块的设计和自动化证据，应作为兼容实现说明阅读，不代表
当前仍提供所有旧 UI。
