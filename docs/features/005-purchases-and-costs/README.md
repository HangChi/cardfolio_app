# Feature 005：购买记录与累计花费

## 目标

用户可记录购买、整套购买和分摊信息，准确计算累计花费，同时保留币种与每笔来源。

## 范围

- 日期、金额、币种、渠道、卖家、运费、手续费、备注；
- 关联多个卡片或套卡；
- 可选分摊但不重复计入累计；
- 退款用独立负向调整；
- 无汇率时按币种分组。

## 追踪

- FR-PUR-001..004；
- BR-COST-001..006；
- NFR-DATA-001、NFR-DATA-002；
- AC-P0-006。

## 数据影响

金额以最小货币单位整数加 ISO 币种存储。购买总额是累计口径，分摊仅用于归因。换算值必须保留汇率、来源和时间，不能覆盖原币种。

## 风险

浮点误差、整套金额重复、退款语义、跨币种伪汇总和关系删除后的审计缺口。

## Definition of Ready

- 金额口径、运费/手续费包含关系和退款示例冻结；
- 购买/分摊/调整数据模型通过财务一致性评审；
- AC-P0-006 与多币种场景有确定夹具；
- 删除关联对象时的购买记录保留规则明确；
- 建立完整九件套后方可实现。
