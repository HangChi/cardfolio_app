# Feature 005：购买记录与累计花费

状态：实现完成，自动化通过，待设备验收
依赖：Feature 001、Feature 003

用户可记录单卡或整套购买、可选分摊和退款调整，并按原币种查看可信的累计花费。

## 本次交付

- 金额、币种、日期、渠道、卖家、运费、手续费和备注；
- 一笔购买关联多个卡片或套卡，关系保留目标名称快照；
- 可选完整分摊，累计只使用购买记录层金额；
- 退款以引用原购买的独立负向调整保存；
- 运费/手续费展示口径可切换，多币种缺少汇率时分组展示；
- schema v5、v4→v5 无损迁移、事务、仓储、Riverpod 和 Widget 自动化；
- 购买列表、创建表单、退款入口及按原币种的入手成本排序。

## 关键口径

`amountMinor` 是商品金额，累计默认等于商品金额 + 运费 + 手续费；展示设置只能排除运费或手续费，不能改写事实。分摊启用时必须覆盖全部目标且合计等于默认累计金额，但不再次进入累计。金额始终以最小货币单位整数和 ISO 币种保存。
