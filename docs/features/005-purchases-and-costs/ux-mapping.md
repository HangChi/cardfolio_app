# Feature 005 UX 映射

| 用户步骤 | 页面 | 行为 |
|---|---|---|
| 查看累计与历史 | 我的 → 购买记录 | 按币种汇总、费用口径开关、时间倒序历史 |
| 新建购买 | 购买表单 | 日期、金额、币种、费用、来源、备注和目标 |
| 选择对象 | 购买表单 | 卡片/套卡分区多选，名称与类型用文字表达 |
| 启用分摊 | 购买表单 | 为每个目标输入金额并实时显示合计/差额 |
| 记录退款 | 购买记录菜单 | 输入退款金额和日期，生成独立负向调整 |
| 查看归因 | 购买历史项 | 展示目标名称快照及可选分摊 |
| 按成本排序卡片 | 收藏 → 卡片排序 | “入手成本”按原币种分组并在组内排序 |

## 视觉方向

沿用 `AppColors` 与 `AppTokens`。累计区使用“账本条”作为识别点：每个币种一项，明确显示当前是否包含运费/手续费。正向购买和负向调整用正负号与文字共同表达，不只依赖颜色。

## 状态

列表、汇总和目标选择覆盖加载、空、成功、失败。保存中禁用按钮；字段错误靠近输入项；长目标名和 200% 字体允许换行，表单整体滚动。
