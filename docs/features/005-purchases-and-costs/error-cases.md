# Feature 005 错误与边界

| 场景 | 用户体验 | 数据保证 |
|---|---|---|
| 金额为空、格式错误或负数 | 标记金额并提示 | 不写入 |
| 币种不是三位字母 | 标记币种并提示 | 不写入 |
| 没有选择目标 | 提示至少选择一个对象 | 不写入 |
| 目标重复或已删除 | 提示刷新后重试 | 不写入 |
| 仅部分目标填写分摊 | 提示补齐或关闭分摊 | 不写入 |
| 分摊合计不等于默认累计 | 展示当前差额 | 不写入 |
| 调整引用不存在/另一调整 | 提示原购买不可用 | 原购买不变 |
| 退款金额非正或币种冲突 | 标记退款金额 | 不写入 |
| 购买项目写入失败 | 提示保存失败 | 整个事务回滚 |
| 缺少汇率 | 分币种显示 | 不产生单一总额 |
| 关联对象后续删除 | 显示名称快照 | 历史与累计保留 |
| schema 迁移失败 | 启动阻断并允许重试 | 不清库、不覆盖旧数据 |
