## Android / iOS 手动验收步骤

1. 在 Android 与 iOS 真机安装 Debug 构建，准备至少两张卡和一个含成员的套卡。
2. 进入“我的 → 购买记录”，新建商品金额 500、运费 20、手续费 5 的 CNY 购买，关联两张卡并填写合计 525 的分摊；保存并重启 App。
3. 确认历史、目标与分摊保留，默认累计为 525；依次关闭运费和手续费，确认显示 505、500，重新开启后恢复 525。
4. 新建 JPY 1,000 的整套购买；确认 CNY 与 JPY 分组展示，不出现跨币种单一总额。
5. 对 CNY 原购买退款 120；确认出现独立 -120 调整，原购买未改变，默认 CNY 累计为 405。
6. 尝试负普通金额、空币种、无目标、分摊缺项和分摊合计错误；确认均阻止保存且没有半条历史。
7. 删除一张已关联卡片或套卡后返回购买历史，确认仍显示保存时名称且累计不变。
8. 在收藏页按“入手成本”排序，确认不同币种先分组，同币种内金额排序稳定。
9. 将系统字体调到约 200%，分别在窄屏 Android 与 iPhone 小尺寸设备检查列表、表单、目标选择和退款弹窗：无文字遮挡、按钮可达、页面可滚动。
10. 开启 TalkBack / VoiceOver，确认金额、币种、费用口径、目标、分摊、退款和保存按钮均可被读出并完成操作。

完成后请把设备列的 `⏳` 改为 `✅`，并记录设备型号、系统版本和异常截图。
