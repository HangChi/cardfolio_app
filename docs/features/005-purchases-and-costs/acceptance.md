# Feature 005 验收标准

## A1 购买事实

用户可填写日期、商品金额、币种、渠道、卖家、运费、手续费和备注，选择一个或多个卡片/套卡后保存。重启后记录和关系仍存在。

## A2 分摊不重复

购买整套商品金额 500，给成员填写合计 500 的分摊后，默认累计只增加 500。分摊不完整或合计不等于购买默认累计金额时不能保存。

## A3 费用口径

商品 500、运费 20、手续费 5 默认累计为 525。关闭运费后为 505，关闭运费和手续费后为 500；设置变化不改写购买记录。

## A4 退款

对 500 的原购买记录退款 120 后，历史同时保留 500 和 -120 两行，累计为 380；原购买字段和关系不变。

## A5 多币种

人民币 500.00 与日元 1,000 的购买在无有效汇率时分别显示 CNY 500.00、JPY 1,000，不出现 CNY 510.00 或其他伪总额。

## A6 删除审计

关联卡片或套卡被删除后，购买历史继续显示保存时的目标名称快照，累计金额不变。

## A7 UI 与可访问性

购买列表覆盖加载、空、成功和失败；保存中禁止重复提交；金额、币种、费用口径、退款和分摊均有文字标签；360、393、430 宽度及 200% 字体下可滚动且操作可达。
