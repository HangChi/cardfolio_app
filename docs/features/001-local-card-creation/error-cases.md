# Feature 001 错误与边界

| 场景 | 用户体验 | 数据保证 |
|---|---|---|
| 选择器取消 | 安静返回 | 无草稿记录、无托管文件 |
| 权限拒绝 | 说明用途，可重试/设置 | 无写入 |
| Android 丢失选择结果 | 启动后尝试恢复 | 同一结果只消费一次 |
| 源文件不可读/格式不支持 | 提示重新选择 | 不进入数据库事务 |
| 名称为空 | 字段级错误并聚焦 | 不调用仓储 |
| 磁盘不足 | 提示释放空间后重试 | 无半成品记录 |
| 图片复制失败 | 保存失败，可保留表单 | 无数据库写入 |
| 数据库事务失败 | 保存失败，可重试 | 事务回滚并删本次文件 |
| 重复保存 | 保持保存中状态 | 幂等 ID 保证单条记录 |
| 进程中断 | 下次启动恢复/清理 | 已提交记录保留；孤儿文件清理 |
| 详情记录不存在 | 提示并返回收藏 | 不自动重建 |
| 数据库打不开 | 阻断页与重试 | 不删库、不覆盖 |

用户文案不得显示 SQL、堆栈、源文件绝对路径或内部异常。日志只记录错误码和操作阶段。
