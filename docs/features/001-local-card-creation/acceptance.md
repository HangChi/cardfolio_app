# Feature 001 验收标准

## A1 空库创建

给定首次安装且数据库为空，当用户从收藏空状态点击“从相册导入”、选择有效图片、填写名称并保存，则：

- 进入卡片详情；
- 收藏列表出现且只出现一条卡片；
- 图片与名称正确；
- 对应 AC-P0-001。

## A2 取消与校验

- 取消系统选择器时停留在来源页，无错误、无文件、无记录。
- 名称为空或只含空白时显示字段错误，不调用仓储。
- 离开未保存表单后不存在数据库记录和正式托管图片。

## A3 重复提交

当保存操作未结束时快速重复点击，仓储只接收一次请求；数据库只有一组定义、藏品和图片；对应 AC-P0-002。

## A4 重启恢复

保存后强制停止并重新启动 App，收藏列表和详情仍可访问，图片能由相对路径解析；对应 AC-P0-003。

## A5 失败恢复

- 图片不可读：不进入表单，提示重新选择。
- 文件复制失败：数据库无记录。
- 数据库事务失败：三张表无残留，本次复制文件被删除。
- 进程在复制后终止：下次启动删除无数据库引用的托管文件。
- 数据库打开失败：不删库，显示重试。

## A6 UI 与可访问性

- 360、393、430 宽度无溢出。
- 200% 字体下仍可完成创建。
- 所有图片和图标按钮具有正确语义。
- 保存中状态可见，按钮禁用。
- 未开放拍摄方式显示“后续开放”且不可执行。

## 验收证据

每项记录自动化测试名称；Android 人工项记录设备、系统、构建号、日期和结果。所有失败必须关联修复或明确阻断发布。
