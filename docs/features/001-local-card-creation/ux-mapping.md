# Feature 001 UX 映射

上游：[Figma 交付基线](../../design/figma-handoff.md)

| 用户步骤 | 页面/节点 | 行为 |
|---|---|---|
| 打开 App | 收藏 `3:71` | 空库显示导入主操作；非空显示列表 |
| 选择采集方式 | 拍摄入口 `3:137` | 仅相册导入可用 |
| 系统选图 | 系统 UI | 取消无副作用，成功进入新建页 |
| 编辑资料 | 新建卡片 `3:211` | 图片预览、名称必填、可选字段 |
| 保存 | 新建卡片 | 显示进度、锁定重复提交 |
| 查看结果 | 卡片详情 `3:253` | 展示图片、名称和已填资料 |

## 页面状态

- 收藏：加载、空、数据、失败、封面缺失。
- 拍摄入口：默认、相册选择中、权限/平台失败。
- 新建：编辑、字段错误、保存中、保存失败。
- 详情：加载、数据、记录缺失、图片缺失、失败。

## 交互差异

Figma 的“05 图片裁切与增强”在 Feature 001 中明确跳过。该差异是已确认范围决定，不视为实现缺陷。精确视觉令牌需在 UI 开发前按 Figma 交付门禁提取。
