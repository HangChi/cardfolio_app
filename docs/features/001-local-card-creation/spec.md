# Feature 001：本地创建卡片闭环

状态：已确认，可进入开发准备
依赖：M0 文档基线
上游：[PRD](../../product/卡迹App_PRD_v1.0.md)
详细设计：[Feature 001 设计](../../superpowers/specs/2026-07-26-feature-001-local-card-creation-design.md)

## 1. 用户结果

用户无需登录和网络，可从系统相册选择一张图片，填写名称及可选资料，保存为本地卡片，在收藏列表和详情页查看，并在 App 重启后继续访问。

## 2. 范围内

- 五入口主导航骨架；
- 收藏空状态、列表、错误与图片缺失状态；
- 拍摄入口及可用的“从相册导入”；
- 系统相册选择单张图片；
- 新建卡片表单；
- `CardDefinition`、`CardItem`、`CardImage` 三实体持久化；
- 受管图片复制、校验和、事务补偿和孤儿清理；
- 卡片详情；
- Android 首轮设备验收，代码保持 iOS 兼容。

## 3. 范围外

相机、裁切增强、连续拍摄、多图、套卡、标签、系列、自定义字段、购买记录、统计、回收站、导入导出、账号和同步均不进入本 Feature。

## 4. 规则

- 名称去除首尾空白后必须非空。
- 单次草稿生成稳定 UUID；重复保存只产生一个藏品。
- `CardItem.quantity` 初始为 1。
- 图片类型为 `front`，排序为 0。
- 数据库只保存托管目录相对路径。
- 取消选择或放弃表单不创建记录。
- 保存成功后进入详情；列表由响应式查询自动更新。
- 数据库打不开或迁移失败时保留原数据并提供重试。

## 5. 需求追踪

- 核心：FR-IMG-001、FR-CARD-001、FR-CARD-002、FR-CARD-004、FR-DATA-001。
- 规则：BR-CARD-001、BR-CARD-002、BR-IMG-001、BR-IMG-002。
- 质量：NFR-DATA-001、NFR-DATA-002、NFR-UX-001、NFR-A11Y-001、NFR-ARCH-001、NFR-TEST-001。
- 验收：AC-P0-001、AC-P0-002、AC-P0-003。
