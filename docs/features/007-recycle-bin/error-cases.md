# Feature 007 错误与边界

| 场景 | 行为 |
|---|---|
| 重复软删除或恢复 | 幂等成功，不重复递增版本 |
| 活跃卡片请求永久删除 | 拒绝并提示先移入回收站 |
| 卡片不存在 | 删除、恢复和永久删除保持幂等；预览返回不可操作 |
| 删除后立即恢复 | 图片与全部定义级关联原样可见 |
| 最后一份同款藏品永久删除 | 保留卡片定义与套卡预期款式 |
| 一个购买包含多个目标 | 只删除该卡片目标，购买和其余目标保留 |
| 图片有原图与派生图 | 两个唯一相对路径均入队 |
| 路径重复入队 | 主键去重，只清理一次 |
| 文件不存在 | 视为清理成功并出队 |
| 文件删除失败 | 数据库删除不回滚；记录尝试并留队 |
| 应用在事务中断 | 整个永久删除回滚，不出现半删除 |
| 应用在文件清理中断 | 队列保留未完成路径，下次启动继续 |
| 保留期边界 | 恰好等于截止时间的条目视为到期 |
| 非法保留天数 | 拒绝写入并显示安全提示 |
| 数据库读取失败 | 显示“回收站暂时无法加载”和重试 |
