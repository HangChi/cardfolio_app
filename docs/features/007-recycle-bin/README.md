# Feature 007：回收站与永久删除

## 目标

删除内容先进入回收站，可恢复或经二次确认永久删除，并让数量、套卡进度和统计一致变化。

## 范围

- 卡片及受支持关联对象软删除；
- 回收站列表、恢复、永久删除；
- 可配置保留期；
- 删除/恢复后的查询、统计和套卡重算；
- 永久删除图片引用与文件。

## 追踪

- FR-DATA-003；
- BR-DEL-001..002、相关 BR-SET/BR-IMG；
- NFR-DATA-001；
- AC-P0-007。

## 数据影响

实体使用 `deletedAt`，默认查询统一排除。永久删除按依赖顺序执行事务，文件删除采用可恢复的待清理队列，避免数据库成功而文件操作中断导致错误状态。

## 风险

级联误删、恢复关系不完整、统计未失效、共享图片误删和保留期后台执行不可靠。

## Definition of Ready

- [x] 每类实体的级联、保留和恢复规则形成矩阵；
- [x] 永久删除确认展示影响数量；
- [x] AC-P0-007 覆盖删除与恢复前后同一查询口径；
- [x] 文件引用计数和中断恢复方案评审完成；
- [x] 建立完整九件套后方可实现。
