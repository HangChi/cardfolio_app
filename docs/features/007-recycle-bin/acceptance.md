# Feature 007 验收标准

1. 从卡片详情删除后，卡片立即从收藏、详情、首页统计、筛选结果和购买目标中消失，并进入回收站。
2. 恢复后，同一张卡片及其图片、标签、系列、自定义字段、购买快照和套卡进度原样回归。
3. 回收站按删除时间倒序展示名称、封面、删除时间和剩余天数。
4. 永久删除前展示将删除的图片数、文件数和购买关联数，并要求二次确认。
5. 永久删除后卡片无法恢复，图片数据库行被删除，受管文件最终被清理。
6. 文件删除中断不回滚已提交的数据库事务；失败路径保留队列，下次启动继续处理。
7. 保留期只允许 7、30、90 天，默认 30 天；启动时自动永久删除已到期项目。
8. 数据库从 v5 升级到 v6 时保留全部既有数据，并创建设置与清理队列表。
9. 空、加载、读取失败和操作失败状态均提供明确中文反馈。
10. 无设备自动化与静态分析通过；设备项未执行时保持“待验收”。
