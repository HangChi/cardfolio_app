# 威胁模型

## 1. 范围

覆盖本地数据库、托管图片、系统选择器、导入导出、未来账号同步和诊断链路。设备已被完全破解不作为 M0 可完全防御的前提，但不得扩大暴露。

## 2. 资产与边界

- 资产：卡片图片、资料、购买记录、删除历史、账号与同步令牌。
- 信任边界：系统选择器到 App、App 到文件系统、App 到 SQLite、导出包到外部存储、Feature 010 客户端到服务端。

## 3. 主要威胁

| 威胁 | 影响 | 控制 |
|---|---|---|
| 恶意或损坏图片 | 崩溃、资源耗尽 | 类型/大小校验、受控解码、失败隔离 |
| 路径穿越 | 读取或删除非托管文件 | 相对路径、规范化、根目录包含检查 |
| 跨资源写入中断 | 数据或文件孤儿 | 事务、补偿删除、启动清理 |
| 导入包篡改 | 覆盖或注入错误数据 | 格式版本、校验和、临时验证、原子提交 |
| 日志泄露 | 用户内容外泄 | 结构化脱敏日志与发布检查 |
| 令牌泄露 | 账号被接管 | 平台安全存储、短期令牌、撤销 |
| 同步重放/冲突 | 数据重复或丢失 | 幂等 ID、实体版本、冲突副本 |
| 供应链依赖 | 恶意代码或构建污染 | 锁定版本、许可证/维护评审、CI 密钥隔离 |

## 4. 安全门禁

涉及文件解析、导入、账号、同步、远端诊断或新权限的 Feature 必须更新本模型。高风险问题阻断发布；中风险问题需要负责人、缓解措施和到期时间。
