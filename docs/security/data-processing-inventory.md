# Feature 010 数据处理清单

| 数据 | 来源 | 本地 | 云端 | 用途 | 删除 |
|---|---|---|---|---|---|
| 邮箱、Auth 用户 ID | 用户/Auth | 非敏感摘要 | Auth | 登录与租户隔离 | 账号删除 |
| 访问/刷新令牌 | Auth | 平台安全存储 | Auth | 会话 | 退出/失效/删除 |
| 设备随机 UUID | App 生成 | sync settings | 请求元数据 | 幂等与设备诊断 | 本地重置/账号删除 |
| 16 类收藏实体 | 用户 | Drift | 私有 Postgres 行 | 跨设备同步 | 单项/账号删除 |
| 原图、派生图 | 用户/App | 私有目录 | 私有 Storage | 跨设备恢复 | 单项/账号删除 |
| 操作 UUID、版本、字段名 | App/服务端 | outbox/state | operations/changes | 重试与冲突 | 保留期/账号删除 |
| 冲突双方载荷 | 两设备 | 本地 conflict | 变更日志现版本 | 用户比较解决 | 解决后本地清理/账号删除 |
| 错误码、次数、耗时 | App/服务端 | 脱敏诊断 | 运营指标 | 可用性 | 环形/运营保留期 |

禁止进入云端或日志：密码、令牌明文、绝对文件路径、SQL/堆栈、未启用同步的收藏内容、
导出包正文和图片像素。服务角色密钥只存在服务端密钥管理。
