# 隐私设计

## 1. 数据分类

| 数据 | 分类 | 默认位置 |
|---|---|---|
| 卡片图片与资料 | 用户私有内容 | App 私有目录与本地数据库 |
| 购买记录 | 财务相关用户内容 | 本地数据库 |
| 账号标识与同步元数据 | 账户数据 | Feature 010 本地数据库与服务端 |
| 诊断事件 | 运行数据 | 本地；启用远端前需单独评审 |

## 2. 最小化

- M0 核心功能无需注册或联网。
- 仅保存完成用户任务所需字段。
- 不读取通讯录、位置、麦克风或无关媒体。
- 图片导入后只保存受管副本；不记录原相册路径。
- 默认不上传图片、卡片内容和购买记录。

## 3. 透明与控制

- 首次需要照片权限时解释用途。
- 导出前展示包含的数据类型与目标位置。
- 删除区分回收站、永久删除和账号删除。
- Feature 010 上线前提供同步开关、隐私说明、数据下载与删除路径。

## 4. 保留

- 活跃数据保留至用户删除。
- 回收站保留周期由 Feature 007 明确，默认不自动永久删除。
- 本地诊断日志采用容量和时间双限制，不保留业务字段。
- 账号关闭后的服务端保留遵循届时发布的隐私政策和法律要求。

## 5. 第三方

任何分析、崩溃、同步或图像处理服务接入前必须完成数据流、地区、保留、删除、SDK 权限和隐私声明评审。没有评审结论不得上传用户内容。
