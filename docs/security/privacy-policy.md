# 卡迹隐私政策（V1 同步基线）

更新日期：2026-07-29

## 我们处理什么

不登录时，卡片资料、图片、标签、套卡、购买记录和设置只保存在设备的 App 私有空间。
用户主动注册并开启同步后，卡迹处理账号邮箱、设备随机标识、同步操作元数据，以及用户
选择同步的收藏资料和图片。密码由认证服务处理；卡迹客户端不保存密码。

## 为什么处理

以上数据仅用于登录、跨设备同步、恢复、冲突处理、数据下载、账号删除、安全防护和
服务健康。默认不用于广告、画像或训练模型，不读取通讯录、精确位置、麦克风或无关媒体。

## 存放与共享

本地数据存于设备 App 私有数据库和目录。云同步首实现使用 Supabase 的 Auth、
Postgres 和私有 Storage；生产部署会在 App 内公布实际运营主体、地区、联系方式和
适用 DPA。除基础设施处理方、法律义务或用户明确指示外，不向第三方披露内容。

## 用户控制

用户可随时关闭同步、退出并保留本地、导出本地备份、下载云端数据、删除单项内容，
或删除账号及全部云端数据。删除账号时可独立选择是否删除设备本地副本。账号删除请求
需二次确认；云端删除完成前不会清除本地唯一副本。

## 保留与安全

活跃云端数据保留至用户删除或账号关闭。幂等操作和变更日志只保留同步可靠性所需期限，
生产值由运营政策公布。令牌存平台安全存储；传输使用 TLS；服务端按账号 RLS 隔离；
图片为私有对象。安全事件按事故响应和适用法律通知。

## 联系与变更

正式发布前由运营主体补充隐私联系人、司法辖区、未成年人政策和监管权利入口。重大变更
在生效前提示；用户不同意新增云处理时可继续只使用本地模式。
