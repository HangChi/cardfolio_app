# 数据保护

## 1. 静态数据

- 数据库与图片位于 App 私有目录，其他普通应用不可直接访问。
- 数据库只保存托管目录相对路径。
- 导出文件由用户主动选择位置，并明确其脱离 App 私有保护。
- Feature 010 的令牌存储在平台安全存储，不进入 SQLite 或日志。

M0 不自行实现数据库加密。若威胁模型、法规或用户研究要求加密，必须采用经过审计的方案并提供密钥丢失、设备迁移和性能测试。

## 2. 传输

- M0 不传输用户内容。
- Feature 010 仅使用 TLS，执行证书、重试、幂等和超时策略。
- 不在 URL 查询参数中传递令牌或用户内容。
- 上传前压缩或处理不得改变原始数据的可恢复性，除非用户明确选择。

## 3. 完整性

- 图片保存 SHA-256 校验和。
- 数据库多表写入使用事务。
- 导出包包含格式版本、清单和校验和。
- 导入先在临时空间验证，完整成功后再提交。
- 同步写入携带实体版本和幂等操作 ID。

## 4. 日志与调试

禁止记录图片字节、卡片名称、备注、购买信息、访问令牌、数据库内容、绝对文件路径。错误日志使用错误码、版本、平台、操作阶段和匿名关联 ID。发布构建关闭调试转储。
