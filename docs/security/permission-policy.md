# 权限策略

## 1. 原则

- 在用户触发相关操作时请求，不在启动时批量请求。
- 能用系统选择器完成时不申请广泛媒体库访问。
- 拒绝权限后核心离线浏览仍可使用。
- 权限文案说明直接用途，不使用诱导性表述。

## 2. 权限矩阵

| 能力 | 权限/系统能力 | 请求时机 | 拒绝处理 |
|---|---|---|---|
| 从相册导入 | 系统照片选择器或最小照片权限 | 点击“从相册导入” | 解释并允许重试/打开设置 |
| 相机拍摄 | 相机权限 | Feature 009 点击拍摄 | 保留相册导入替代路径 |
| 文件导入导出 | 系统文档选择器 | 用户发起导入/导出 | 不修改现有数据 |
| 网络同步 | 网络能力，不弹运行时权限 | Feature 010 用户开启同步 | 保持本地可用并提示状态 |

不得申请位置、通讯录、麦克风、后台定位或广泛存储权限，除非未来 Feature 有独立 PRD、安全评审和明确用户价值。

## 3. 平台检查

- Android 按目标 SDK 验证照片选择器和权限模型。
- iOS 提供完整用途描述，验证受限照片库。
- 权限状态变化后重新查询，不缓存永久假设。
- 自动化测试覆盖首次拒绝、永久拒绝、受限、允许和系统取消。
