# 卡迹 Cardfolio

卡迹是一个本地优先的交通卡收藏管理应用。当前已实现本地建卡、多图、套卡、标签、
系列、筛选、购买账本、首页摘要、统计下钻与回收站；数据保存在本地收藏库，并可在
应用重启后恢复卡片与图片。

## 当前范围

- 五入口应用壳：首页、收藏、拍摄、统计、我的。
- 收藏卡片、套卡与系列，支持搜索、组合筛选、稳定排序和待补资料。
- 从系统相册导入并管理多张图片、用途、顺序和封面。
- 名称、城市、发行机构、发行时间、编号、备注、类型、标签和自定义字段。
- 精确购买金额、分摊、退款与按原币种累计。
- 首页收藏摘要、最近录入、即将集齐、待补资料。
- 六维数量统计、原币种月度成本趋势和收藏列表下钻。
- Drift/SQLite 本地持久化与 App 私有图片存储。
- 保存幂等、事务失败补偿、启动孤儿图片清理。
- 卡片软删除、完整恢复、二次确认永久删除与 7/30/90 天保留期。
- 永久删除图片文件的持久化清理队列与启动重试。
- 数据库启动失败时保留原文件并提供“重试”。

导入导出、相机拍摄与裁切增强、账号与同步尚未开放。

## 本地开发

需要已配置 Flutter SDK 和 Android SDK。在项目根目录依次运行：

```powershell
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter analyze
flutter test
flutter run
```

运行持久化集成测试时，请指定一个已连接设备：

```powershell
flutter devices
flutter test -d <device-id> integration_test/card_persistence_test.dart
```

构建 Android debug APK：

```powershell
flutter build apk --debug
```

## 验收平台

首轮验收目标是 Android 模拟器或真机。核心路径包括：

1. 空收藏启动；
2. 取消一次系统相册选择，确认没有生成卡片；
3. 选择有效图片；
4. 验证空名称提示；
5. 快速点击两次保存，确认只创建一张卡；
6. 强制停止并重启应用；
7. 确认收藏列表、详情和图片仍可访问。

生产 Dart 代码和插件配置保持 iOS 兼容；macOS/iOS 构建与真机验证需在 macOS
环境补充。

## 数据位置与安全

数据库和图片保存在平台提供的应用支持目录下。数据库仅记录受管图片的相对路径，
不会依赖系统相册中的原文件持续存在。数据库打开失败时应用不会自动删除或重建
现有数据。
