# 卡迹 Cardfolio

卡迹是一个本地优先的交通卡收藏管理应用。当前已实现本地建卡、多图、套卡、标签、
系列、筛选、购买账本、首页摘要、统计下钻、回收站、完整备份和可选账号同步；本地
数据库始终是读取源，并可在应用重启后恢复卡片与图片。

## 当前范围

- 五入口应用壳：首页、收藏、拍摄、统计、我的。
- 收藏卡片、套卡与系列，支持搜索、组合筛选、稳定排序和待补资料。
- 从系统相册导入并管理多张图片、用途、顺序和封面。
- 使用系统相机单张/连续拍摄，并支持边缘建议、手动四角、透视、旋转、基础增强和展示模板。
- 原图保持不可变，派生 JPEG 独立保存并可在保存前比较、撤销和重置。
- 名称、城市、发行机构、发行时间、编号、备注、类型、标签和自定义字段。
- 精确购买金额、分摊、退款与按原币种累计。
- 首页收藏摘要、最近录入、即将集齐、待补资料。
- 六维数量统计、原币种月度成本趋势和收藏列表下钻。
- Drift/SQLite 本地持久化与 App 私有图片存储。
- 保存幂等、事务失败补偿、启动孤儿图片清理。
- 卡片软删除、完整恢复、二次确认永久删除与 7/30/90 天保留期。
- 永久删除图片文件的持久化清理队列与启动重试。
- 可验证的完整 ZIP 备份、空库恢复与仅新增合并导入。
- 可选邮箱账号、同步开关、持久化 outbox、增量游标、附件和指数退避重试。
- 多设备不同字段自动合并；同字段和删除/修改碰撞生成可比较的冲突副本。
- 退出保留本地，账号删除时可独立选择是否删除本地副本。
- 数据库启动失败时保留原文件并提供“重试”。

未注入服务地址时 App 保持纯本地模式。测试/生产同步服务通过 HTTPS 地址注入：

```powershell
flutter run --dart-define=CARD_FOLIO_API_BASE_URL=https://sync.example.com
```

## 本地开发

需要已配置 Flutter SDK 和 Android SDK。Windows 使用 Flutter 插件时需先开启开发者
模式以允许创建符号链接。在项目根目录依次运行：

```powershell
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter analyze
flutter test
flutter run
```

运行持久化集成测试时，请指定一个已连接设备：

```powershell
flutter devices
flutter test -d <device-id> integration_test/card_persistence_test.dart
```

构建 Android debug APK：

```powershell
flutter build apk --debug
```

## 验收平台

首轮验收目标是 Android 模拟器或真机。核心路径包括：

1. 空收藏启动；
2. 取消一次系统相册或系统相机，确认没有生成卡片；
3. 单张拍摄、连续拍摄并选择有效图片；
4. 验证空名称提示；
5. 快速点击两次保存，确认只创建一张卡；
6. 强制停止并重启应用；
7. 确认收藏列表、详情、原图和派生图仍可访问。

生产 Dart 代码和插件配置保持 iOS 兼容；macOS/iOS 构建与真机验证需在 macOS
环境补充。

## 数据位置与安全

数据库和图片保存在平台提供的应用支持目录下。数据库仅记录受管图片的相对路径，
不会依赖系统相册中的原文件持续存在。数据库打开失败时应用不会自动删除或重建
现有数据。
